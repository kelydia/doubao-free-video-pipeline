# 优化升级计划（借鉴 Higgsfield AI 电影方法论）

> 本文件是本仓库（`doubao-free-video-pipeline`）的持续演进路线图。
> 主体：豆包网页版免费额度自动出图/出视频流水线（现有工程能力）。
> 借鉴来源：Higgsfield《Hell Grind》《The Cully Hill Boys》两片开源的方法论（下称「Higgsfield 方法论」）。
> 原则：**只借鉴方法论层（创作一致性），不动已验证的工程层**（5 分钟硬停 / 看图成本 / 切号 / 锚点先行 C 模式）。
> 状态图例：⬜ 未开始 · 🟨 进行中 · ✅ 已完成 · ⏸ 暂缓

---

## 0. 背景与判断

现有流水线「手」极强（浏览器确定性校验、额度自动切号、审图成本纪律、锚点先行 C 模式、合成脚本齐全），
但「脑」偏商品展示型：一致性靠单张 `product_anchor.md`，缺叙事级的资产体系、空间/机位量化、表演写法。

**Higgsfield 方法论的核心总纲**：
> 「一致性就是全部工作，视频模型没有记忆。」("Consistency is the entire job. Video models have no memory.")

本计划把这句总纲和它衍生的 5 条支柱，逐条补进现有流水线。优先级 = 从「商品转盘 → 叙事短片」时最先崩的地方排起。

## 2. 逐项详述

### U0 · 一致性总纲写入主线（P0）
- **现状**：`工作流_SOP.md` 有「一镜一件事」「因果链」，但无一句总纲点破「为什么」。
- **改动**：在 `_shared/工作流_SOP.md` 开头加「第一性原理」小节，把一致性总纲作为判断标尺。
- **验收**：SOP 首屏可见总纲；每条硬规则可回溯到总纲。
- **状态**：⬜

### U1 · 资产系统（P0，最先崩的一环）
- **现状**：只有 `product_anchor.md`（颜色 hex / 配件 / 包装），只覆盖商品；人物/场景/道具无分层，无版本。
- **改动**：
  1. 新增 `_shared/资产系统规范.md`：定义 资产 = 文字描述(逐字进提示词) + 参考图 + 版本号；
     分四层（角色卡 / 场景基图 / 道具 / 状态态）；状态即资产（换装/受伤=独立资产，只改变化的部分）；
     命名 `@char_<项目>_<名>_vN` / `@loc_...` / `@prop_...`，同名贯穿资产-提示词-画布可追溯。
  2. 角色卡三禁忌（去头双身 / 双表情特写 / 禁 studio 词 / 空手 / 无轮廓光 / 扛 10 次仍可辨）。
  3. `product_anchor.md` 保留为「商品层」；新增模板 `_shared/templates/_asset_index_template.md`。
- **验收**：规范文档 + 模板可用；T3 模板可演示「商品层」如何嵌入资产体系（不强行改 T3 本体）。
- **状态**：⬜

### U2 · 空间/机位量化 + 表演写法（P0）
- **现状**：`专题手册/01_提示词与动作设计.md` 偏商品展示，缺空间地图、镜头度数、表演写法。
- **改动**：在 `专题手册/01` 新增「叙事镜专用」章节：
  1. **空间地图**：几行平面图，写一次逐镜粘贴，位置绑可见地标（"在灯旁/画面左"），显式「就三个人其余空」。
  2. **镜头用度数**：10 个锚点 180/135/107/84/63/47/29/18/12/8°；可靠带 29–84°；每镜锁死防漂中景。
  3. **表演写肌肉**：下颌收紧/手停住/颊骨绷紧取代形容词；1 句内心独白；行为替代情绪；声音是锁定条件不是资产。
- **验收**：章节内含可直接复制的模板常量；与现有「一镜一件事」不冲突。
- **状态**：⬜

### U3 · 提示词三层 writer / reviewer / workbench（P1）
- **现状**：提示词「一次写好就发」，无独立审查层。
- **改动**：在 `专题手册/01` 增加「发前自检（reviewer 清单）」：查空首帧、陈旧标签、空间矛盾、自相矛盾、重复 tag；
  workbench 原则：只补失败片段，不重写整条提示词。
- **验收**：一份发前自检清单（可勾选）；不增加过度流程负担。
- **状态**：⬜

### U4 · Watcher 审片角色（P1）
- **现状**：有 `anchor_gate.py` 做衔接判定，无整片「技术存在但不成立」的专岗。
- **改动**：在 `工作流_SOP.md` §6 合成质检处新增「Watcher 通看」步骤与判定清单（空首帧 / 表情跳变 / 动作不同步 / 道具数量）。
- **验收**：SOP 增加一步且不破坏现有锚点先行流程。
- **状态**：⬜

### U5 · 剪辑与生成并行 + 简化镜头（P2）
- **现状**：剪辑放末段（§6 合成在 1 天后）。
- **改动**：`工作流_SOP.md` 说明剪辑可与 §5 视频生成并行；补「镜头救不回来就改镜头不改句子」一条。
- **验收**：SOP 措辞更新，附一句理由。
- **状态**：⬜

## 3. 执行纪律

1. **一项一提交**：每个 U 项独立 commit，message 前缀 `feat(Ux):`，可单独回滚/评审。
2. **不改已验证工程**：切号 / 5 分钟硬停 / 看图纪律 / C 模式 一律不动。
3. **验证方式**：文档类改动用「结构自检 + 与现有条目无冲突」；涉及模板的用 `verify_t3_template.py` 或最小样例跑通。
4. **状态回写**：每项完成后更新本文件对应行状态（⬜→✅）并在 §4 变更记录追加。
5. **每次提交后复扫敏感信息**（`scripts/scan_secrets.py` 逻辑，脱敏 0 命中）。
