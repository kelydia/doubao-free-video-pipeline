## 两个模板的共同方法内核

1. **六拍叙事**：悬念 → 事件 → 命中/揭示 → 聚焦 → 展示 → CTA。
2. **去 AI 味**：无口播 + 无人脸（只露手）+ 脏环境（雨天/瑕疵）+ 不完美光 + 浅景深手机感 + 克制运镜。
3. **锚点先行（C 模式）**关键帧流程：先锁相邻镜首帧，再出尾帧对齐，改图比改视频便宜约 20 倍。
4. **衔接判定**：以「上镜末帧 + 下镜首帧」两联图为准，drift 数值只作参考。
5. **音效**：氛围底噪 + 关键节点点缀；输出 loudnorm I=-16。
6. **看图纪律**：一律用 `review_sheet.py`（strip/pair/one），严禁直读原图。
