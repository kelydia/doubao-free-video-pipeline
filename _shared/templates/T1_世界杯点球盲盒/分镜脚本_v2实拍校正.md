## 新增：目标箱高亮（后期叠层）

S2 / S3 里给"本期目标箱"叠一个**呼吸光圈**（金色细环 + 缓慢明暗脉动），位置参数化：

```
target_col = 1..6      # 第几列，从画面左起
target_row = upper/lower
```

这样换 SKU 时不用重渲任何镜头，只改一个数字。后期用 PIL 生成逐帧 PNG 序列叠上去即可。
