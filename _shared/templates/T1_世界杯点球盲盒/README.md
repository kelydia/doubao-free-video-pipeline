# 模板 T1 · 世界杯点球盲盒（Penalty-Kick Box Reveal）

> 一支「世界杯夜场罚点球 → 箱子入网 → 开箱见商品」的竖屏带货短片模板。
> **A 轨（固定片）渲一次全店复用；B 轨（开箱见商品）每 SKU 一条。**
> 来源项目：`2026-11-13_世界杯点球盲盒`（已定稿交付）。

---

## 0. 一句话用法

拿到一个新商品 SKU → 复用整条 A 轨（25s）→ 只重做 B 轨的 **S9 开箱镜**（约 4s）→ 合成一条完整视频。20+ 个 SKU 共用同一条 A 轨，边际成本只有 S9 一条。

## 2. 六拍叙事模型

```
悬念(高空球场) → 事件(点球) → 命中(箱入网) → 揭示(箱飞来) → 聚焦(开箱) → CTA(结算/SHOP NOW)
```

对应 A 轨镜头：
| 镜 | 拍点 | 秒 | 画面 / 动作 |
| --- | --- | --- | --- |
| S1 | 悬念 | 4.0 | 高空垂直俯拍，球场长轴竖直、球门在上部中央，极缓慢前推 |
| S2 | 悬念 | 3.5 | 箱墙正前低机位透过球网，轻推+微下压（箱墙 6列×2层=12只） |
| S3 | 事件 | 4.0 | 点球点后方贴地，三色球压点球点，球门与箱墙景深虚化 |
| S4 | 事件 | 4.5 | 球员身后 3m 背影，缓慢推近，肩膀起伏一次深呼吸 |
| S5 | 事件 | 3.0 | 贴地侧后方，脚背击球、草屑水珠爆开 |
| S6a | 命中 | 2.0 | 球撞顶层箱 → 箱歪斜 15–20° 留顶部 → 球弹飞（**拆分镜头**） |
| TRANSIT | 揭示 | 4.0 | 箱脱网 → 朝镜头飞来变大 → 箱盖掀开露米白纸丝（**过渡镜，桥接 S6a→S9**） |
| S9 | 聚焦/CTA | 4.0 | 35° 俯角近景，纸箱里米白纸丝 + 商品，展示/取出 |

> **A 轨最终形态 = S1→S2→S3→S4→S5→S6a→TRANSIT（共 25.0s）**。
> 早期的 S6b/S7/S8 已弃用（原因见 §7）。

## 3. A 轨 / B 轨分层（核心设计）

- **A 轨**（`01_plan/storyboard.json` 的 `tracks.A`）：全店复用，**只渲一次**。产物是可独立播放的 25s 固定片，带 GOAL! 花字。
- **B 轨**（`tracks.B`）：`S9` 每 SKU 一条 4s 开箱镜。**唯一随商品变化的镜头**。
- **接口**：A 轨末帧（TRANSIT 开箱镜 = 掀盖纸箱 + 米白纸丝 + 暖灯虚化）与 S9 首帧机位/纸箱角度/背景一致，**天然衔接，无需转场**。

### 换商品时只需改 4 样
1. `00_input/product_anchor.md`（新 SKU 锚点卡：颜色/配件/包装/禁止项）
2. `01_plan/storyboard.json` 里 S9 的 `refs` 换成该 SKU 的单款参考图（**只给一张，防多款混淆**）
3. S9 提示词里的商品描述段（务必写死材质/颜色/包装形态）
4. 合成时拼 A 轨 + 该 SKU 的 S9

## 5. 关键参数（照抄即可）

- 球：vintage 1998 三色球，白底 + 蓝红弧块，**无商标无文字**。
- 球员：藏青球衣**无号码**，只出背影/腰以下，**永不露脸**。
- 箱墙：6 列 × 2 层（12 只）。**箱数与商品数无关**——它是固定奖池格子。
- 看台：压暗成深蓝散景，零可辨人脸。
- 箱墙参考：`K2_boxwall` 实为 6 列×2 层（不是最初设想的 18 只）；`K6_box_net` 机位偏近、顶部有 119px 黑边需裁（见 §7）。

## 6. 生产流程（SOP 摘要，完整见 `_shared/工作流_SOP.md`）

1. **参考视频逆向**（如有参考片）：1fps 抽帧 → 逐秒结构表 → 六拍叙事 → 去 AI 味手法清单。
2. **商品锚点卡**（最易返工）：具名锚点、配色表、**包装写最前**（决定所有负向词）、禁止项、一致性自检。
3. **分镜双版本**：`storyboard.json`（机器读）+ `分镜脚本.md`（人读）。
4. **关键帧生成（锚点先行 C 模式）**：每环先锁 `S(n)_first + S(n+1)_first` → 出 `S(n)_last` 对齐 → 跑视频 → 抽末帧对比 → 放行或修下一镜首帧。**改图比改视频便宜约 20 倍**。
5. **单镜视频生成**：每镜预期 1–3 次重跑；`_prev/` 存旧版；每镜出片后必做「末帧 vs 下一镜首帧」两联对比。
6. **合成与质检**：`compose_v3_nocap.sh` 合成（默认不放大，720×1280）→ `concat_nocap.sh` 拼接 → 叠 BGM/音效 → 三张质检图（7镜总览/逐秒/交界帧）。

## 7. 踩坑清单（本项目血泪，复用必看）

1. **复合物理动作一定要拆镜**：模型把「箱墙不倒 + 箱倒进网 + 网鼓包」理解成「掉到地上」，一次完不成 → 拆成 S6a（撞箱）+ TRANSIT（脱网飞来开箱）。原则：**每段只做一件简单的事**。
2. **参考图会「带入」元素**：图里有球，模型必画球（S6b/S7 那颗「复活球」）。**用参考图前先检查有没有不该出现的元素**；最好换天然无球参考图或改用静态补位镜。
3. **后期抹球全失败**：球压在箱角/网绳/背景交界处，ffmpeg delogo→拉伸斑块，cv2 inpaint→放射糊斑，球横跨画面中部无法裁剪。**唯一干净解法：换无球参考图 / 静态补位镜 / 重渲**。
4. **参考图顶部黑边要裁**：`K6_box_net` 顶部 119px 纯色黑边（RGB 22,36,36），用 `scripts/trim_k6_ref.py` 裁掉。
5. **两段独立生成的视频机位对不上**：硬切帧间差异 45.4 vs 正常 7-10。正确做法：**用前一镜末帧做首帧参考，生成一条「桥接」过渡镜**，让机位变化由新镜头自身演掉。
6. **动作型镜头把起始状态写成「动作已完成一半」**成功率更高（S5 踢球经验：写「球已在空中、脚已停半空」，而不是「从头做这个动作」）。
7. **推镜幅度**：主体贴镜头构图（点球/特写）比远景箱墙更易被推爆，要显式写「4秒内主体高度只增加不到10%」。
8. **豆包出片耗时约 5-7 分钟**（不是文档说的 2-3 分钟），wait 正则需要覆盖「你的视频生成好了」变体。
9. 视频只有 720×1280；水印位置会跳（底部/左上），须逐帧核验。**交付默认 720×1280 不放大**（见 `_shared/复盘_2026-11-15.md:39`），放大到 1080×1920 仅为可选步骤。

## 9. 定格收尾（避免「取出悬浮」穿帮）

用户要求 S9 段「取出一半前定格 2 秒结束」，避免 AI 取出动作穿帮：
- S9 播放到 t≈1.6s（商品仍在包装内、手在袋口）后**定格该帧 2.4s 至 4s**，总长仍对齐。
- 实现：单条 `filter_complex`，视频 `trim 0:1.6` + `loop 2.4s` concat；音频 `atrim 0:25` + `anullsrc atrim 0:(1.6+2.4=4)`。
- **坑：silence 时长必须 = FREEZE_T + HOLD = 4s，否则音频只有 27.4s**。
- 脚本参考 `scripts/freeze_s9_v2.mjs`。
