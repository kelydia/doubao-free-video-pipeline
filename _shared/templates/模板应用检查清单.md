# 模板应用检查清单

> 用任一模板开新任务时，逐项打勾。详细的流程见各模板 README 与 `../工作流_SOP.md`。

## A. 开工前（10 分钟）

- [ ] 读对应模板的 `README.md`（含规格/分镜/参数/踩坑）
- [ ] 读 `_shared/工作流_SOP.md`（尤其 §4.5 看图成本纪律）
- [ ] **账号额度预检（强制，手册 05）**：`taskSpace("<任务名>")` 动态重连 → 面板列出 ≥2 个账号（正则 `/用户[A-Za-z0-9]+/`）→ 当前账号 `quotaExhausted()==false`；视频批次脚本必须 import `_shared/scripts/acct_switch.mjs` 并实现「额度耗尽 → 自动切号 → 重提当前镜头」，禁 `quota→break`；每次提交/切号写 `_shared/账号额度台账.md`
- [ ] 豆包浏览器脚本按 [`豆包网页版操作手册.md`](../豆包网页版操作手册.md) 的 5 条确定性校验执行，实现走 `_shared/scripts/doubao_ui.mjs`；「稳 vs 省」的取舍交人工
- [ ] 确认 ffmpeg / python 路径：
      - ffmpeg/ffprobe：`D:/Portable/ffmpeg-9.0.2-essentials_build/bin/`
      - PIL python：`C:\Users\李爱华\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe`
      - 看图：`_shared/scripts/review_sheet.py`
- [ ] 建任务目录 `<YYYY-MM-DD>_<主题>/`，按模板 §10 标准结构分层
- [ ] **问清 5 个问题**（SOP §7）：商品图在哪 / 参考视频精准复刻还是只借结构 / 真实包装什么样 / 花字中英无 / 时长与是否口播
- [ ] **视频生成前的关键帧人工确认（强制，2026-11-16）**：把本批次每镜的关键帧 / 首尾帧图发给用户看并取得明确「通过」后才提交视频生成；修复 / 重出场景额外发「上一镜末帧 + 本镜首帧」两联图；同批次内关键帧未变更的切号重提无需重发。详见工作区 `AGENTS.md`。

## B. 商品锚点卡（最易返工，先做）

> 详细字段见模板 `product_anchor.md`；要点：具名锚点（颜色 hex / 配件形状材质 / 可数元素）、配色表（主+辅+禁止色）、**包装写在最前面**、禁止项、一致性自检规则。

## C. 分镜（双版本）

- [ ] `01_plan/storyboard.json`（机器读）
- [ ] `01_plan/分镜脚本.md`（人读）
- [ ] 每镜 4–6s；节点帧只在复杂动作时加；因果链显式（上镜末状态 = 下镜首状态）
- [ ] T1 / T3：标好 A 轨（固定 25.0s）与 B 轨（S9 4.0s）分层
- [ ] **T3 专属**：确认「得分框有没有网」→ 本版**无网**，S6a 只做撞箱歪斜脱墙，不写入网 / 网鼓包 / 脱网动作

## D. 关键帧（锚点先行 C 模式）

- [ ] 每环先锁 `S(n)_first + S(n+1)_first`，再出 `S(n)_last` 对齐下一镜首帧
- [ ] 出图后 `finalize_frames.py` 裁水印 + 缩放 1080×1920
- [ ] contact sheet 分批送审（一次 4–8 张），用户确认才进视频
- [ ] **带参考图前检查有没有不该出现的元素**（球 / 球网 / 网绳 / 扶球手 / 礼盒 / 多余人物）；T3 尤其查参考图里**有没有网**，有就重出
- [ ] **逐对核对 `storyboard.json` 的 `joins` → `must_match`**：每一对相邻镜的 must_match 元素必须同时写进两镜提示词（本次 S3→S4 要求「椭球在开球座上」，但 S4 提示词写了「一颗球都没有」直接抹掉）
- [ ] **禁止句不得与 must_match 元素冲突**：写「不要让 X 出现」前先查 X 是不是必须保留的元素；宁可写「保持 X 不动、不被遮挡」
- [ ] **T3 专属**：每条正向提示词都写 `the goalposts have NO net, only open empty night air behind them`；若首轮仍凭空长出网 → 先删负向词 `soccer goal net / net ropes`，再换无网参考图，**不要后期抹**

## E. 单镜视频

- [ ] 每镜预期 1–3 次重跑；旧版进 `_prev/`
- [ ] 出片后抽末帧，与下一镜首帧做两联对比（`review_sheet.py pair`）
- [ ] **逐对抽两联图，不能只核最后一处衔接**：覆盖 `joins` 里每一对相邻镜（本次只核 S6a→TRANSIT，漏掉 S3→S4，直到用户看成片才发现球消失）
- [ ] 偏离大 → **默认建议修下一镜首帧图**（比改视频便宜 20 倍）
- [ ] **任何重跑先人工确认**（图或视频都算）

## F. 合成与质检

- [ ] `compose_v3_nocap.sh` 合成（**默认不放大**，输出 720×1280）
- [ ] `concat_nocap.sh` 拼接
- [ ] T1 / T3：A 轨 + 各 SKU 的 S9 合成；S9 可取前 1.6s + 定格 2.4s（`freeze_s9_v2.mjs`）
- [ ] 交付分辨率**720×1280，不放大**（唯一权威 `复盘_2026-11-15.md:39`）；放大到 1080×1920 仅为可选步骤
- [ ] 叠音效（`mix_audio_v3.mjs`，loudnorm I=-16，去掉 7.5s 哨声）
- [ ] 若引入外部音效 / 特效素材（见 `_shared/外部素材资源库.md`）：逐条核对授权、登记来源 URL / ID / 协议、回填「已采用记录」；**换音效 = 改混音，先人工确认**
- [ ] 三张质检图：7 镜总览 / 逐秒 / 交界帧（全部用 review_sheet.py）
