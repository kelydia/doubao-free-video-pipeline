## 6. 生产流程（SOP 摘要，完整见 `_shared/工作流_SOP.md`）

1. 开工先查模板：**A 轨能复用就是 0 额度**；本模板 A 轨须重新生成（画面主题变了）。
2. **C 模式锚点先行**：先锁 `S(n)_first + S(n+1)_first`，再出 `S(n)_last` 对齐；改图比改视频便宜约 20×。
3. 四环生成顺序（每环出两联图送审，一次只发 4–8 张）：
   ```
   环 1 环境（软闸门）      K1 → K2 → K3
   环 2 人 + 动作（硬闸门）  K3 → K4 → K5
   环 3 物理交互（硬闸门）   K5 → K6 → K7   ← 最易翻车，留足额度
   环 4 B 轨（可批量）       K7 → K8_<SKU>
   ```
4. 每镜 4–6s（豆包滑块 4–15s），后期剪到 `storyboard.json` 的 `seconds`；出片 5–7 分钟/镜，`done` 正则要覆盖「你的视频生成好了」。
5. 衔接判定：**以「上镜末帧 + 下镜首帧」两联图为准**（`review_sheet.py pair --h 620`），drift / mean_abs 只作参考。
6. 看图纪律：永不直读 720×1280 / 1080×1920 原图，一律先过 `_shared/scripts/review_sheet.py`；一次调用只发一张图；动作/机位/数量用 `strip --h 330`，包装/材质用 `one --h 900`。
7. **任何重跑（关键帧/视频/换提示词/换账号）一律先向用户说明原因与成本，得到人工确认后才执行。**

## 7. 踩坑清单（橄榄球新增 3 条；通用 9 条见 T1）

> **通用 9 条踩坑（拆镜 / 参考图带入 / 后期抹元素失败 / K6 黑边 / 桥接镜 / 动作已完成一半 / 贴镜头高度 / 出片耗时 / 水印跳动）唯一权威见 [`../T1_世界杯点球盲盒/README.md`](../T1_世界杯点球盲盒/README.md) §7**，不在此逐字复述。

**T3 新增 3 条**：

10. **⚠️ 无网陷阱（本版头号风险）**：橄榄球门柱没有球网。负向词里写 `soccer goal net / net ropes` 本身也会激活「网」的概念。
    因此每条正向词必须显式写 `the goalposts have NO net, only open empty night air behind them`；
    若首轮仍凭空长出网，**先删掉这两个负向词**（只留 `white rectangular soccer goal frame`），
    再换一张无网参考图，不要靠后期抹。
11. **holder 陷阱**：真实 field goal 需要扶球手按住球，但为守「只有一个球员」硬约束**刻意省略**。
    所有提示词不得出现 holder / 扶球的手；K3 负向词必须含 `a hand holding the ball, holder kneeling`。
12. **`球`不能画成正圆**：模型见过太多足球，容易把 American football 画成圆形或黑白五边形。
    正向词锁死 `prolate spheroid, pointed at both ends, two white rings, white lace stitching`，
    负向词加 `round soccer ball, black-and-white pentagon pattern, white/blue/red tricolor retro football`。

> 而 T1 `README.md` 与 `_shared/复盘_2026-11-15.md:41-47` 已定稿 v3（25.0s）。

## 12. 主题变体：如何做第 3、第 4 个运动

工程层（A/B 轨、六拍、镜头与时长、拆镜、TRANSIT、音效、定格、变体、脚本资产）**一个字都不用改**，只换 `关键帧提示词.md` 与 `视觉规范.md` 的视觉层。

**英式橄榄球 Rugby 只换 3 处**：
1. 门柱：U 形 + gooseneck → **H 形**（两立柱 + 横梁，无弯颈；仍无网）。
2. 球：删白色环带与鞋带缝线，改更圆钝的 `rugby ball, plumper prolate spheroid, no laces, no white rings`。
3. 球员：删头盔/面罩/护肩，改 `short-sleeve rugby jersey, no helmet, no shoulder pads, short dark hair, back to camera`；负向词反向加 `helmet, shoulder pads, facemask`。

花字可顺带 `FIELD GOAL!` → `PENALTY KICK!`（可选，不影响任何镜头）。

**其它运动填空表**：篮球→篮筐（有网，需把 T1 的「入网」物理加回来）；冰球→球门网；棒球→本垒打墙。
判定口诀：**只要「得分框有没有网」变了，就先改 S6a 的命中物理链，再改提示词**。
