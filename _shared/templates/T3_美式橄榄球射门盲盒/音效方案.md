## 3. 可选微调（非必需，需人工确认后才动）

- **触球音色**：`kick_ball_final.wav` 是足球触球声（偏清脆）。橄榄球是尖头厚皮革，脚背击球更闷更沉。
  若听感违和，**优先在混音脚本里对该段加 `lowpass=f=2200` 或 -2dB 高频衰减**，不要换文件、不要重新拟音 —— 保持「复用」优先。
- **花字同步**：`GOAL!` → `FIELD GOAL!`，20.6s 的欢呼峰值仍对齐花字出现帧；无需改音频。
- **不加**头盔 / 护肩碰撞声：全片只有一个球员、无对抗冲撞，加了反而穿帮。

## 4. 输出规格与定格收尾

- 输出：`loudnorm I=-16`，48kHz，立体声。
- 混音脚本：直接复用 `2026-11-13_世界杯点球盲盒/scripts/mix_audio_v3.mjs`（路径按新任务软链接或复制引用）。
- **S9 定格收尾**：S9 播到 t≈1.6s 后定格该帧 2.4s 至 4s（商品仍在包装内、未取出）。
  实现单条 `filter_complex`：`trim 0:1.6` + `loop 2.4s` concat；音频 `atrim 0:25` + `anullsrc atrim 0:4`。
- **坑（沿用 T1 §9）**：`silence` 时长必须 = `FREEZE_T + HOLD = 4s`，否则音频只有 27.4s，比画面短。
- 定格脚本：直接复用 `2026-11-13_世界杯点球盲盒/scripts/freeze_s9_v2.mjs`。
