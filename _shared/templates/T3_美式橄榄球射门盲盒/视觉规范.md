# 美式橄榄球射门盲盒 · 视觉规范（Visual Bible）

> 状态：v1 · 2026-11-15 · 由模板 T1「世界杯点球盲盒」换运动主题皮而来
> 适用：本任务全部关键帧（图像生成）与单镜视频（视频生成）提示词
> **本文件只定义「橄榄球视觉层」；工程结构、镜头序列、方法论 100% 沿用 T1，见 `复用清单.md`。**

## 0. 五条硬约束（沿用 T1，措辞按橄榄球校正）

| # | 约束 | 落地方式 |
| --- | --- | --- |
| 1 | 箱子数量不绑定商品数 | 箱墙固定 **6 列 × 2 层 = 12 只**（沿用 T1 v3 定稿值，不是 v1 的 9×2=18）；商品只在最后一只箱子里换，箱位不动 |

## 1. 空间轴线（全片唯一的运动轴，原样沿用 T1）

竖屏最怕横向摇镜。本片把整条轴线定为：

```
     U 形门柱 + 箱墙（永远在画面上部）
            ↑
     开球座 + 橄榄球（射门点）
            ↑
     踢球手背影
            ↑
     镜头（永远在球员身后）
```

- 高空俯瞰：**球场长轴竖直**，进攻方向朝画面上方，目标端区与门柱在上部中央。
- 推镜只允许**沿这条轴向前 + 逐渐降低机位（俯角从 70° → 0°）**，不做侧向横移、不做环绕。
- 这样 S1 的高空机位和 S4 的地面机位落在**同一条直线上**，切点才藏得住。

> 为什么不能「门柱在画面底部」：那样推下来会从门柱上方飞过去，接不上地面「球员身后」的机位，必须多一次 180° 转向 —— AI 视频最怕这个（T1 §7-5 血泪）。

## 2. 球场与夜场氛围（替换层 #1）

| 项 | 规格 |
| --- | --- |
| 场景 | **美式橄榄球场**：100 码比赛区 + 两端各 10 码端区，夜间比赛（超级碗夜场感） |
| 草坪 | 深浅相间的割草条纹沿长轴延伸；**白色码线（yard lines）与短标线（hash marks）**横向分布，白漆磨损、踏痕、轻微枯黄斑 |
| 端区 | 端区地面为同一片草皮，**不出现队徽、端区文字、大字 logo**（AI 出字必乱码） |
| 灯光 | 四角泛光灯柱，灯头柔和高光晕；主光从**右上方**打下（全片固定，不换光位） |
| 空气 | 薄雾 + 体积光 + 细小雨丝，让灯柱有光锥 |
| 看台 | 压暗成深蓝色散景，只有零星亮点；**禁止**观众面孔、看台文字、赞助商板、记分牌 |
| 道具 | 相机广告板、角旗、啦啦队、边裁一律回避 |

**门柱（替换层 #2，最关键）**：

- **亮黄色 U 形门柱**（goalposts）：两根竖直立柱 + 一根水平横梁 + 一根弯颈支撑柱（gooseneck），位于端区后沿。
- 颜色 `#E8B93A` ~ `#F2C94C`，漆面有细微磨损与雨痕。
- **绝对没有球网、没有网绳、没有白色矩形门框** —— 这是与 T1 最本质的差别，见 §3。
- 门柱始终在画面上部，作为「得分框」的视觉标识，不参与物理互动。

**调色**：低饱和青绿冷调，高光泛暖（3200K 灯光），暗部偏青。胶片颗粒轻微。
**禁止**：大面积纯黑、HDR 过曝、霓虹紫粉（会显得像电竞，不 grass roots）。

## 3. 箱墙与「命中」的物理（替换层 #6，结构差异最大）

- **位置**：箱墙码在**端区前沿、U 形门柱正下方前方的草皮上**，沿端线一字排开。
- **数量**：6 列 × 2 层 = 12 只，上下两层交错码放（上层压在两箱接缝上更真实）。
- **箱体**：
  - 本色牛皮纸（`#C8A87A` ~ `#B08D5E`），表面有折痕、压痕、箱角磕碰变形；
  - 两道半透明封箱胶带（`#E8E4DC`，半透）；
  - **绝对不要印刷文字、编号、标签、logo**（AI 出字必乱码，且会破坏「未知奖品」的悬念）。
- **命中箱**：中间那一列的上层箱（`target_col` 默认 3，1 起数）。它是全片唯一会移动的箱子。

> **⚠️ 与 T1 的最大结构差异：橄榄球门柱没有网。**
> T1 的 S6 是「球撞箱 → 箱后仰翻入网 → 网鼓起回弹」，还因此拆成 S6a/S6b 两个镜头。
> 本版把「入网 / 网鼓包 / 网回弹」**整段删除**，S6a 只做一件事：球撞中间列上层箱，箱歪斜 15–20°、
> 开始脱离箱墙；「箱彻底脱墙 → 朝镜头飞来 → 掀盖露纸丝」全部交给桥接镜 TRANSIT。
> 物理更简单，反而更贴合 SOP「一镜只做一件事」，且**不需要 S6b 拆分镜**。

## 4. 橄榄球（替换层 #3）

**不要写品牌名**（Wilson / NFL / Super Bowl 会被拒或被改成乱码字）。

统一描述为：

> 一颗 **American football**：brown pebbled-leather prolate spheroid（`#8B4A2B` ~ `#A6532F`），
> pointed at both ends，两道白色环带靠近两端，一侧有白色鞋带式缝线（white laces），
> 磨砂荔枝纹皮革、表面有使用磨损与泥点、缝线清晰，**无任何商标与文字**。

- 球**立在一只浅棕色开球座（kicking tee）上**，或压在草皮上压出浅浅草痕；球面有湿亮反光。
- 真实 field goal 需要扶球手（holder）按住球，但本片为守住「只有一个球员」硬约束，**刻意省略 holder，球置于开球座**，踢球手独自助跑起脚。所有提示词都不得出现扶球手。
- 全片只有这一颗球，**不出现第二颗**。
- **负向补充**：圆形足球、黑白五边形、白底蓝红三色复古足球、篮球、排球、橄榄球形状的球被画成正圆。

## 5. 球员（替换层 #4）

- 只出**背影 / 腰以下 / 侧后 45°**，任何镜头不见正脸、不见五官；头盔面罩本身就是遮脸保障。
- 藏青球衣（`#1B2A44`），**无号码、无姓名、无队徽**；**亮银白头盔（`#D8DCE0`）+ 深色面罩**；明显宽肩的护肩轮廓；白色球裤、白色球袜、黑色踢球鞋。
- 短发不可见（头盔覆盖）、职业体型；球衣下摆被风掀起一点。
- **只有一个球员**，不出现队友、防守球员、裁判、教练、扶球手、门将（门将/防守方出现 = 要扑救/拦截 = 物理崩溃，直接不给他们）。

## 8. 单镜生成参数（原样沿用 T1 §8）

- 图像：1080×1920 竖图，出图后裁水印条并缩放到目标尺寸（`finalize_frames.py`）。
- 视频：9:16，**豆包时长滑块最小 4s、最大 15s** → 所有镜头按 4–6s 生成，后期再剪到目标时长。
- 每镜提交 1–2 张参考图（本镜首帧 + 关键节点/尾帧），提示词结构化：`画面 + 机位 + 动作 + 光线 + 一致性锁 + 负向词`。
- **参考图带入元素检查**（T1 §7-2）：挂参考图前逐项确认图里没有不该出现的东西（球、文字、多余人物）。橄榄球版尤其要检查参考图里**有没有球网** —— 一旦有，模型会在无网场景里凭空画一张网。
