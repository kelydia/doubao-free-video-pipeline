## 3. 与 T1 的因果链差异（必读）

T1 的命中链是：

```
S5 踢球 → S6a 球撞箱歪斜 → S6b 已压网的箱再下沉、网鼓包回弹 → S8 箱脱网飞来 → S9 开箱
```

本版因**橄榄球门柱无网**，收敛为：

```
S5 踢球 → S6a 球撞箱歪斜并开始脱墙 → TRANSIT 箱脱墙飞来 + 掀盖露纸丝 → S9 开箱
```

三条硬规则：

1. **一镜只做一件事**（T1 §7-1 / SOP §3）：S6a 绝不塞「撞 + 倒 + 飞」；脱墙与掀盖全部由 TRANSIT 承担。
2. **TRANSIT 是桥接镜，首帧必须严格 = S6a 末帧**（T1 §7-5）：用 S6a 末帧做唯一参考图生成，让机位变化由新镜头自身演掉，衔接处**不要白闪、不要硬切**。这是 T1 里最漂亮的一次修复，原样复用。
3. **参考图不带球网**：所有参考图（尤其 K6 / K7）生成前逐项检查，画面里出现网绳就让模型重出 —— 否则无网场景里会凭空长出一张网。

## 5. 关键帧链路与生成顺序（沿用 T1 四环 C 模式）

```
环 1（环境，软闸门）：K1 → K2 → K3
环 2（人 + 动作，硬闸门）：K3 → K4 → K5
环 3（物理交互，硬闸门，最易翻车，多留额度）：K5 → K6 → K7
环 4（B 轨，可批量）：K7 → K8_<SKU>
```
