## 2. 结构与创作语法（可迁移的部分）

### 2.1 六拍叙事模型
```
[街头悬念: 异常发生] → [遗落: 诱饵出现] → [揭晓: 拆箱] → [开格: 手指寻宝] → [产品: 取出举示] → [CTA/尾板]
```
对应参考视频就是：卡车送礼盒 → 箱子掉在路边 → 拆胶带掀盖 → 24 格倒计时盲盒 → 抠 24 号取小盒 → 取出挂件举示 → TikTok 尾板。

**结构性卖点**：整条片子没有一句口播，靠**画面叙述 + 顶部固定花字**（"Everyone NEEDS this before Christmas 🎄"）承担全部信息。这个花字**全程固定在画面上方**，几乎不换行、不换位置——是这条片子的记忆点。

### 2.2 让"AI 生成"看不出 AI 味的手法（复刻时必须保留）
1. **环境是脏的**：雨天湿路面、水洼、沥青颗粒、轮胎痕、黄色双实线掉漆。真实感来自"不干净"。
2. **光是不完美的**：阴天散射 + 湿路面镜面反射 + 桥洞逆光，没有一处甜美布光。
3. **手是本人的手**：黑色橡胶手套、指节褶皱、动作略笨拙（撕胶带撕两下才开）。**全片没有出现人脸**，规避了 AI 人脸的恐怖谷。
4. **产品出现前有大量铺垫**：整整 9 秒才见到产品，前面全是"开"的动作，把好奇心拉满。
5. **产品举示时的浅景深**：焦点在挂件上，背景盒子糊掉，是手机微距镜头的真实表现。
6. **镜头语言克制**：几乎全是固定机位 + 轻微手持，没有炫技运镜；只有拆箱时略微推近。

## 3. 与原片的差异（有意为之）

1. **参考视频无口播**：本片同样不配口播，只用 BGM + 顶部花字，保证"去 AI 味"——AI 配音是最容易露馅的环节。
2. **参考视频全片无人脸**：本片也**不出现人脸**，只出现手，规避 AI 人脸问题。
3. **场景从户外转入室内**：商品是圣诞树挂饰，室内圣诞场景比户外更合理；但保留户外"掉箱"的悬念段（S1–S2），做到"先户外后室内"的转场。
4. **商品露出更早**：原片 12s 才见产品，本片总长 34s，在 S3 尾帧（约 9s）就已露出 3 款，S5（约 13-19s）单品微距，S6 举示，节奏更紧凑。
5. **改 3 格**：原片 24 格倒计时 → 本片 3 格圆窗（用户 m00164：「只有3款小熊挂件，不需要24格，就3个格子」）。

## 4. 拍摄/生成对照清单（写入每镜 prompt 的"质感约束"）

- 路面：湿沥青、水洼镜面、黄色双实线磨损、沥青颗粒。
- 纸箱：牛皮纸纤维、折痕、胶带反光、边缘磨损。
- 手套：米白针织，起球、指节褶皱、有轻微污渍。
- 室内：暖黄实用光（2700–3000K）+ 窗边冷调补光（5000–5500K），灯串散景，浅景深。
- 镜头：35–50mm 等效，手机微距时最近对焦距离感，轻微手持抖动，无稳定器感。
- 禁止：完美对称构图、无瑕表面、塑料光泽、过饱和、HDR 感、文字/水印。
