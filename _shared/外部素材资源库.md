## 5. 授权与合规（商用带货短视频，必读）

1. **我们的成片是电商带货用途**，属于商业使用。优先用筛选栏的「**免费商用 (cc协议)**」；逐条打开素材页确认协议类型（是否要求署名 / 是否允许商用 / 是否允许改编）。
2. 页面同时存在「**版权**」类（实测计数 257）与「商用版权音效」入口 —— **这类必须购买授权后才能用**，不能因为能下载就当成免费。
3. 「免费」≠「免费商用」：下载类型里的「免费」只说明不扣积分 / 不收费，授权标签要单独看。
4. 每条采用的素材必须登记：来源 URL、素材标题 / ID、授权类型、协议链接或截图、下载日期、使用位置（时间点 + 镜头）。
5. 无法确认授权的素材**一律不入库**；宁可继续用已定稿的现有音效。

## 6. 归档约定

- 音频文件 → 任务目录 `05_audio/sfx/`（或按子类 `05_audio/<子类>/`），命名沿用现有风格：`kick_ball_final.wav`、`box_thud_final.wav`。
- 视频 / 特效类素材 → 不要塞进 `02_keyframes/ 03_clips/ 05_audio/`；在任务目录新建 `07_assets/`，并在 `任务总结.md` 里登记用途与授权。
- 下载后统一转 `48kHz` 立体声；混音输出仍是 `loudnorm I=-16`（沿用 `mix_audio_v3.mjs`）。
- 采用后回填 §8「已采用记录」，并同步更新该任务 `01_plan/音效方案.md` §5 资产清单。

## 7. 纪律（与工作区规范一致）

- **不得直接替换 T1 / T3 已定稿音效时间轴**；本资源库只是「备选 / 扩充来源」。
- 换音效 = 改混音 = 一次重跑：按全局规范「重跑必须人工确认」，先说明原因与成本、得到确认后才执行。
- 替换后必须重跑 `mix_audio_v3.mjs`，并复核三件容易漏的事：7.5s **无哨声**、S9 定格 `silence = 4s`（否则音频只有 27.4s）、`loudnorm I=-16`。
- 引入外部特效 / 视频素材时，不破坏 T3 硬约束：门柱**无网**、全片**只有一个球员且不露人脸**、箱体**无印刷文字**、无队徽无商标、全片英文花字。
- 参考图 / 素材会「带入」元素（T1 踩坑第 2 条）：任何外部素材进关键帧 refs 前，先按「无网 / 无 holder / 无第二颗球」逐项检查。
