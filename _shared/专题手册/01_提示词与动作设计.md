# 专题手册 01 · 提示词与动作设计

> 来源：`2026-11-11` / `2026-11-13` / `2026-11-15` 三次项目实测。
> 主干流程见 [`../工作流_SOP.md`](../工作流_SOP.md)；本文是 SOP §3 / §5 的展开，专治「视频动作不对」。

---

## 1. 铁律：一镜只做一件事

**复合物理动作写进一条 4 秒提示词，模型只会完成一半，另一半演错。**

| 案例 | 一条提示词里塞了什么 | 实际结果 |
| --- | --- | --- |
| S6 v1/v2/v3 | 箱墙不倒 **+** 箱倒进球网 **+** 网鼓包 | 箱只倾斜 **15°** 没倒进网、网面零鼓包、一只箱滑落草地；模型把「倒进球网」理解成「掉到地上」 |
| S10 v2 | 依次装 3 只小熊 **+** 撕离型纸封口 **+** 举起展示 | 只装进 1 只（花环款）、袋半透、无封口、中途单独举熊，动作乱 |
| S5 v1 | 从助跑完成抽射随挥 | 球没踢出、人倒退（被理解成倒放） |

**正确做法：拆成两个镜，每镜只锁一个动作。**

- S6 → `S6a_impact`（球撞顶层箱 → 箱歪斜 15–20° 留在顶部 → 球弹飞）+ `S6b`（箱再下沉 → 网鼓包 → 回弹）。两镜各一次通过。
- S10 → `S10a_packing`（依次把 3 只全装进袋、箱清空、不封口）+ `S10b_seal_show`（揭封口贴 → 下翻 → 压平 → 举起）。各一次通过。

写分镜时，凡出现「**撞+倒入网**」「**踢+随挥**」「**装+封+举**」这类连接词，先拆。

## 2. 动作型镜头：起始状态写成「动作已完成一半」

不要写「从头做这个动作」，写「动作已经发生，现在只演收尾」。

**S5 正反例**：

- ❌ v1：「右脚继续完成抽射随挥」→ 模型理解成球还在原地，演成倒放（球没踢出、人倒退）。归档 `03_clips/_prev/S5_strike_v1_ballnotkicked.mp4`。
- ✅ v2：「**球已在空中飞向右前方、脚已停在半空**」+ 在【绝对禁止的错误】里反写「球绝对不许停在脚下，必须已飞出画面」「腿绝对不能向后回撤」→ 一次通过。

S6a 同理：起始就是「球已贴近箱面」，只演撞击与弹飞。

**为什么**：视频模型对「动作起点」的想象力远弱于对「画面状态」的复刻力；给它一个已完成的中间态，它只需沿时间轴往前推一点。

## 3. 运镜约束

| 规则 | 说明 | 反例 |
| --- | --- | --- |
| **只沿一条轴推镜 + 降机位，不侧移不环绕** | 俯角 70°→0°、球门永远在画面上部；否则要 180° 转向，AI 最怕 | — |
| **硬切优于长推镜** | 每段小位移 + 固定机位，比一条长镜头稳 | v2 实拍校正结论 |
| **主体贴镜头的构图显式写幅度上限** | 「4 秒内主体在画面里高度只增加不到 10%」 | S3 球从占画面 **1/6 放大到 1/2**，末帧顶到下缘；远景箱墙（S2）写「推近幅度非常小」+ 给 4 秒则控制良好 |
| **镜头静止要写死** | 「镜头完全静止，机位、视角、箱墙大小位置数量必须始终与参考图一模一样」「开头有几只结尾就必须还有几只」 | S6 v1 镜头一路后退、箱子越变越少 |

## 4. 负向词与人物镜

- **负向词必须点名具体物体**：只写「不要礼盒」压不住；要写「深绿色雪花礼盒、圆窗硬盒、棉纸托盘」。
- **手部/手套形态写死**：连指 mitten / 分指 glove，否则每次都不一样。
- **画面里冒出不存在的文字**：显式加「不出现任何文字/型号/品牌字样」（Q 项目曾冒出 `AEX714`）。
- **人物镜方向写死**：S4 写「永远只看到背影和后脑勺，绝对不要转身 / 回头 / 露侧脸」→ 人物镜第一次就一次过。
- **建议**：把负向词做成模板常量，拼在每条提示词尾部，避免漏写。

## 5. 参考图数量与内容审核拒绝

- **只挂 1 张参考图**（或最多 2 张）最稳。豆包视频面板**没有首帧/尾帧槽位**，多图只会互相干扰。
  - S6 v1 箱数变少，根因是第二张参考图 `K6_box_net` 本身只露 2 只下层箱，模型照着删。
  - S9 三款各只给「该款一张」单款参考图，防三款混淆。
- **提示词过长 + 参考图过多 + 敏感措辞 → 内容安全拒绝**：S10b 首版 6 张参考图 + 「撕开 / 露出粘胶」等措辞，豆包直接回「抱歉，我无法回答你的问题」。
  - 解法：refs 减到 3 张 `[S10b_start, act_r4_fold, act_r5_press]`，措辞换中性词「揭开封口贴 → 提平袋口向下翻折 → 手掌按压贴合」→ 通过。
- **结构化提示词建议顺序**：`【规格】` → `【起始画面】` → `【镜头运动】` → `【动作链】` → `【绝对禁止的错误】` → `【光影氛围】`。中文引号一律用「」，写完必须 `json.load` 校验（半角 `"` 会导致 `SyntaxError: Expected ',' or '}' after property value in JSON`）。

## 6. 商品材质措辞（以实拍原图为准）

锚点卡文字写「毛绒 / 短绒针织」，但商品实为**硬质树脂 / 黏土挂饰**，导致 K8 关键帧三轮返工：

| 版本 | 措辞 | 结果 |
| --- | --- | --- |
| v1 | 毛绒 / 针织 | 全做成毛绒布偶，全废 |
| v2 | 光滑釉面反光 | 材质对但过头，用户「都有种釉面光泽，原图没有」；款4 帽上多绿叶 |
| **v3 ✅** | 「**哑光树脂/黏土质感：细腻颗粒、哑光不反光、无釉面高光和镜面反射、立体堆叠奶油霜般雕刻肌理；绝不是毛绒布偶/布料，也不是亮面陶瓷/釉面**」；款4「纯粉色帽、帽上绝对没有绿叶图案」 | 三款造型全部正确 |

**规则**：材质描述必须同时给出「是什么」和「不是什么」，且以**实际白底原图**为准，不凭锚点卡文字想象。

生成图天生偏鲜亮糖果色，需降饱和到莫兰迪奶油调：PIL 迭代 `0.72 → 0.5 → 0.45 → 回调 0.62 饱和 / 0.99 亮度 / 0.98 对比`，逐款对比原图确认。

## 7. 叙事／角色镜专用（借鉴 Higgsfield 方法论）

> 以上 §1–§6 面向**商品转盘**；做**人物、对话、多角色同框**的叙事镜时，额外补这三把锁。
> 共用底层仍是「一镜一件事」；本节只加「几何一致的量化语言」和「表演的写法」。

### 7.1 空间地图（Space Map）——治穿帮、换位、跳机位

- 每个场景**写一次平面图**（几行即可），然后**逐镜逐字粘贴**进提示词，不许凭记忆。
- 位置绑**可见地标**，不绑距离：
  - ✅「A 在落地灯旁、画面左侧；B 在沙发前、画面右侧；摄影机在房间南端朝向北」
  - ❌「A 在 B 左边两米」（模型没有米的概念，会乱放）
- 每镜明确**机位在哪一侧**（同一场戏的机位一旦定了就别过轴，否则人物左右互换）。
- 显式写人数上限：「画面里**正好三个人，其余全空**」（不写，模型会补龙套）。
- 三个高频病一次治：**瞬移**（位置写全）、**人物互换**（绑地标+定轴）、**机位跳**（机位方向每镜写死）。

### 7.2 镜头用「度数」不用「毫米」

- 镜头一律写**视场角度**：`180 / 135 / 107 / 84 / 63 / 47 / 29 / 18 / 12 / 8°`（10 个锚点）。
- **可靠工作带 29–84°**；更极端值模型容易糊或变形，非必要不用。
- 每镜**锁死一个度数**。不写，模型会默认滑向中间景别，导致同场戏景别忽远忽近、接不上。
- 例：「85mm 中景」→ 改写「**47° 视场、中景、机位在人物眼睛高度**」。

### 7.3 表演写「肌肉」不写「形容词」

- 情绪词（愤怒/悲伤/惊讶）模型只会给你一个**夸张脸**。改写**可观察的身体事件**：
  - ✅「下颌收紧、颊骨绷紧、呼吸变浅、手指在裤缝上停住」
  - ❌「他非常愤怒」
- 加**一句内心独白**（台词里不出现「怀念/嫉妒/心疼」这些词，但模型会据此反推微表情）。
- **行为替代情绪**：写「想要什么 → 遇到什么阻碍 → 策略怎么变」，每次策略变化都是一个**可见动作**。
- **声音是锁定条件，不是资产**：音色/语速/口音每次逐字粘贴复用，别指望"同一个人"的声线一致。
- **静态镜要有微事件**：每 1–2 秒一个微动作（眨眼分阶段、手指轻动），写「held tension」而不是「who moves」。
- **活镜头三标志**：反应先于台词结束就启动；情绪不瞬间清零（留个尾巴缝到剪辑点）；手始终有事做（最强的强调=手停住的那一刻）。

### 7.4 与其他规则的关系

- 与 §1「一镜一件事」不冲突：空间地图是"这一件事发生在哪、机位朝哪"，动作链仍是单件事。
- 与 §3「运镜约束」叠加：先定机位侧（7.1），再定这条轴怎么推（§3）。
- 与 §4「人物镜方向写死」叠加：方向写死 + 空间地图 = 人物镜一次过的双保险。

### 7.5 动作必须写「质感」，不只写「形状」（2026-11-16 兵马俑 R1 教训）

- **只写动作形状会得到软绵绵的慢动作**：写「她张开手伸向俑」→ 出成"缓慢侧向摊手、像讨东西"。要的是**猜拳出布**——短促、有力、干脆。
- 写法：**形状 + 速度 + 力度 + 定格**四件套。
  - ✅「她**啪一下快速**把右手向上出拳，五指张开掌心朝上，**干脆有力像孩子在玩猜拳**，然后**定格保持**在出布姿态不动」
  - ❌「她张开右手伸向俑」
- **游戏化动作要点明「像在玩」**：出拳/猜拳/击掌这类，加 "quick, crisp, decisive stroke" "like a child playing a game"，比单纯描述手型稳得多。
- **每个动作给一个「起手—定格」**：给模型明确的时间锚（前一半起手、后一半定格），避免全程一个慢动作。

## 8. 提示词三层：writer / reviewer / workbench

> 借鉴 CINEDANCE 的三层架构。核心不是多写，而是**发之前有人挑刺**、**失败之后只补坏掉的那一段**。

### 8.1 三层分工

| 层 | 谁 | 干什么 | 产出 |
| --- | --- | --- | --- |
| **writer（写）** | 我 | 按 §7 模板把这条提示词写全 | 一条完整提示词 |
| **reviewer（审）** | 我，切换成挑刺视角 | 发之前逐条对照 §8.2 清单自查 | 通过 / 打回改哪句 |
| **workbench（修）** | 我 | 出片失败时**只改坏掉的那个片段**，不重写整条 | 最小改动版 |

### 8.2 发前自检清单（reviewer 用，逐条打勾）

- [ ] **空首帧**：首帧是否可能一片空/无主体/只有背景？→ 必须首帧就有主体或明确空镜意图。
- [ ] **陈旧标签**：提示词里是否残留上一版场地/服装/道具的描述（复制模板常见病）。
- [ ] **空间自洽**：位置是否与空间地图 (7.1) 一致？机位侧是否过轴？
- [ ] **自相矛盾**：有没有「必须出现 X」和「不要出现 X」同时存在（§D 检查清单第 2 条踩过）。
- [ ] **tag 只出现一次**：同一资产名/关键词不要在多个块里重复（重复 tag 是常见拒绝/混淆原因）。
- [ ] **度数已锁**：镜头视场角写了吗？在 29–84° 带内吗？
- [ ] **时长已定**：视频镜是否写了明确时长（豆包默认 10s 陷阱，SOP §5）。
- [ ] **负向词点名**：负向是不是具体物体，而不是「不要别的」。
- [ ] **必须保留 vs 禁止**：想写「不要礼盒」前，先查礼盒是不是本镜 must_match 的元素。
- [ ] **JSON 可解析**：中文引号用「」，`json.load` 能过。

### 8.3 workbench 原则（只补不重写）

- 出片失败先定位**失败的那一个片段**（哪个动作/哪一帧），**只改那一句**，不推倒重写整条提示词。
- 每次只改一处（总纲纪律「一次一变量」），并在版本日志记下改了哪句、为什么。
- 若改了 3 次仍不成立，**回到"简化镜头"**（见 U5 与总纲第 5 条），而不是继续堆措辞。

## 9. 视频作参考复刻法（media_to_video）：单段一镜到底

> ⚠️ **平台适用范围（强制·2026-11-17）**：本节 media_to_video（视频作参考）**仅适用于「豆包 App / 工作任务模式 / `doubao-video-replica` skill」这条轨**，把原片视频本身当参考、单段一镜到底。
> **网页版浏览器主管线不支持传参考视频**（见 [`../工作流_SOP.md`](../工作流_SOP.md) §0 能力边界表、[`02_参考图_衔接与补救.md`](02_参考图_衔接与补救.md) §5）——网页版复刻/续拍只能走「图生视频 + 原片末帧当首帧」或「拆镜 + 关键帧当参考图」。
> **选错平台会白烧整轮额度**（2026-11-17 兵马俑任务血泪）。开工前先确认你手上是「网页版」还是「App/工作任务/skill」，再决定走本节还是走拆镜。
>
> 来源：2026-11-17 用户贴出豆包"工作任务模式"一次性做出接近 1:1 复刻的完整思路与提示词。它不用文字描述构图、不拆多镜，而是**把原片视频本身当结构/动作/运镜参考**，单段一镜到底逐时间段写死。这正好补上我们在「兵马俑送礼」复刻里反复栽的三个坑：左右站位看反、拆镜后衔接崩、每镜返工。

### 9.1 什么时候用

- **（在 App / 工作任务 / skill 轨）复刻优先于拆镜**：只要目标是用原片（或任何参考视频）复刻一段连续表演（< 15s、单场景单机位、一镜到底），**优先走 media_to_video 单段复刻**，而不是先拆成 8–9 张关键帧再逐镜生成。**网页版没有这条路，只能用拆镜/图生视频**（见本节顶部平台范围）。
- 拆镜路线只在「需要逐镜精修某几拍」「段间要插入原创二创内容」时才值得付衔接成本。
- 取舍（写进交接必标注）：
  - **单段一镜到底**：站位/动作/运镜天生锁死不易跑偏，省衔接麻烦；但**难逐镜修**，一处不满要整条重出。
  - **拆镜多段**：好逐镜小改；但**衔接极易崩**（末帧→首帧对不上），且构图靠参考图锁，文字描述必跑偏。

### 9.2 五段式模板（照抄结构，逐段填）

```
## 1. 输入资产定位与 0 秒基准
<视频1>仅作为剧情、人物站位、动作顺序、场景陈设与运镜节奏参考：[写清采用的空间关系与互动流程]；
不参考、不继承其中[要剥离的主体：真人脸型/五官/发型/发色/服装配色]。
剥离原片所有文字覆盖层（字幕/角标/水印/二维码/贴纸），不继承任何文字。
0 秒：[写清第 0 秒的画面——机位、主体在哪、谁看向谁、环境]。

## 2. 参考主体绑定与生成目标
复刻一段[景别/风格]互动短片：[一句话写清谁做什么动作链、怎么收尾]。
出镜人物为完全虚构的 AI 形象，不对应、不指向任何现实真人：[脸型/五官/发型/发饰/服装逐项重设计]。
全片同一空间、同一人物与服装，[光影/色彩/动作速度]；无出镜人物开口说话，全片静音。

## 3. 逐时间段动作、声音与脚本
A–B 秒：[谁、在哪、做什么、手部接触点、景别、镜头怎么动]。
B–C 秒：[……同上……]。
C–D 秒：[……收尾动作……]。
全程静音，无人声无音乐无环境声无拟音；画面不出现任何字幕/标题/花字/贴纸/水印/Logo/二维码/随机文字。

## 4. 转场与尾态收束
单段连续拍摄，无切镜/无叠化/无闪白。结束在[尾态描述]，不追加片尾定格、卡片或文字。

## 5. 全片一致性与禁区
[人物]的脸型/五官/发型/发色/发饰/服装全程一致，不得生成与原片真实人物或任何现实真人相似、可被识别对应的面部。
[道具/配角]全程一致，不自行移动/不换姿态。手部招式清楚、五指完整自然。
画面干净，不出现多余路人/杂物/文字/水印/二维码/贴纸；不添加旁白/对白/配乐/音效。
```

### 9.3 必写项（漏一个就容易翻车）

- **0 秒基准**：写死第 0 秒机位与主体位置——不然模型自己发挥构图（我们踩过"三俑同框""左右反"）。
- **手部接触点**：出拳/递物这类，写清"谁的哪只手、伸到哪、和什么接触"，别只写"做猜拳"。

- **剥离所有文字**：在第 1 段（不继承任何文字）和第 5 段（画面不出现任何字）各写一次，比只在镜末写 `no Chinese characters` 稳。
- **虚构主体声明**：真人肖像一律"完全虚构、不指向任何现实真人 + 逐项重设计脸/发/衣"，未成年人标准更高。
