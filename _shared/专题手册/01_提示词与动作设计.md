# 专题手册 01 · 提示词与动作设计

> 来源：`2026-11-11` / `2026-11-13` / `2026-11-15` 三次项目实测。
> 主干流程见 [`../工作流_SOP.md`](../工作流_SOP.md)；本文是 SOP §3 / §5 的展开，专治「视频动作不对」。

---

## 1. 铁律：一镜只做一件事

**复合物理动作写进一条 4 秒提示词，模型只会完成一半，另一半演错。**

| 案例 | 一条提示词里塞了什么 | 实际结果 |
| --- | --- | --- |
| S6 v1/v2/v3 | 箱墙不倒 **+** 箱倒进球网 **+** 网鼓包 | 箱只倾斜 **15°** 没倒进网、网面零鼓包、一只箱滑落草地；模型把「倒进球网」理解成「掉到地上」 |
| S10 v2 | 依次装 3 只小熊 **+** 撕离型纸封口 **+** 举起展示 | 只装进 1 只（花环款）、袋半透、无封口、中途单独举熊，动作乱 |
| S5 v1 | 从助跑完成抽射随挥 | 球没踢出、人倒退（被理解成倒放） |

**正确做法：拆成两个镜，每镜只锁一个动作。**

- S6 → `S6a_impact`（球撞顶层箱 → 箱歪斜 15–20° 留在顶部 → 球弹飞）+ `S6b`（箱再下沉 → 网鼓包 → 回弹）。两镜各一次通过。
- S10 → `S10a_packing`（依次把 3 只全装进袋、箱清空、不封口）+ `S10b_seal_show`（揭封口贴 → 下翻 → 压平 → 举起）。各一次通过。

写分镜时，凡出现「**撞+倒入网**」「**踢+随挥**」「**装+封+举**」这类连接词，先拆。

## 2. 动作型镜头：起始状态写成「动作已完成一半」

不要写「从头做这个动作」，写「动作已经发生，现在只演收尾」。

**S5 正反例**：

- ❌ v1：「右脚继续完成抽射随挥」→ 模型理解成球还在原地，演成倒放（球没踢出、人倒退）。归档 `03_clips/_prev/S5_strike_v1_ballnotkicked.mp4`。
- ✅ v2：「**球已在空中飞向右前方、脚已停在半空**」+ 在【绝对禁止的错误】里反写「球绝对不许停在脚下，必须已飞出画面」「腿绝对不能向后回撤」→ 一次通过。

S6a 同理：起始就是「球已贴近箱面」，只演撞击与弹飞。

**为什么**：视频模型对「动作起点」的想象力远弱于对「画面状态」的复刻力；给它一个已完成的中间态，它只需沿时间轴往前推一点。

## 3. 运镜约束

| 规则 | 说明 | 反例 |
| --- | --- | --- |
| **只沿一条轴推镜 + 降机位，不侧移不环绕** | 俯角 70°→0°、球门永远在画面上部；否则要 180° 转向，AI 最怕 | — |
| **硬切优于长推镜** | 每段小位移 + 固定机位，比一条长镜头稳 | v2 实拍校正结论 |
| **主体贴镜头的构图显式写幅度上限** | 「4 秒内主体在画面里高度只增加不到 10%」 | S3 球从占画面 **1/6 放大到 1/2**，末帧顶到下缘；远景箱墙（S2）写「推近幅度非常小」+ 给 4 秒则控制良好 |
| **镜头静止要写死** | 「镜头完全静止，机位、视角、箱墙大小位置数量必须始终与参考图一模一样」「开头有几只结尾就必须还有几只」 | S6 v1 镜头一路后退、箱子越变越少 |

## 4. 负向词与人物镜

- **负向词必须点名具体物体**：只写「不要礼盒」压不住；要写「深绿色雪花礼盒、圆窗硬盒、棉纸托盘」。
- **手部/手套形态写死**：连指 mitten / 分指 glove，否则每次都不一样。
- **画面里冒出不存在的文字**：显式加「不出现任何文字/型号/品牌字样」（Q 项目曾冒出 `AEX714`）。
- **人物镜方向写死**：S4 写「永远只看到背影和后脑勺，绝对不要转身 / 回头 / 露侧脸」→ 人物镜第一次就一次过。
- **建议**：把负向词做成模板常量，拼在每条提示词尾部，避免漏写。

## 5. 参考图数量与内容审核拒绝

- **只挂 1 张参考图**（或最多 2 张）最稳。豆包视频面板**没有首帧/尾帧槽位**，多图只会互相干扰。
  - S6 v1 箱数变少，根因是第二张参考图 `K6_box_net` 本身只露 2 只下层箱，模型照着删。
  - S9 三款各只给「该款一张」单款参考图，防三款混淆。
- **提示词过长 + 参考图过多 + 敏感措辞 → 内容安全拒绝**：S10b 首版 6 张参考图 + 「撕开 / 露出粘胶」等措辞，豆包直接回「抱歉，我无法回答你的问题」。
  - 解法：refs 减到 3 张 `[S10b_start, act_r4_fold, act_r5_press]`，措辞换中性词「揭开封口贴 → 提平袋口向下翻折 → 手掌按压贴合」→ 通过。
- **结构化提示词建议顺序**：`【规格】` → `【起始画面】` → `【镜头运动】` → `【动作链】` → `【绝对禁止的错误】` → `【光影氛围】`。中文引号一律用「」，写完必须 `json.load` 校验（半角 `"` 会导致 `SyntaxError: Expected ',' or '}' after property value in JSON`）。

## 6. 商品材质措辞（以实拍原图为准）

锚点卡文字写「毛绒 / 短绒针织」，但商品实为**硬质树脂 / 黏土挂饰**，导致 K8 关键帧三轮返工：

| 版本 | 措辞 | 结果 |
| --- | --- | --- |
| v1 | 毛绒 / 针织 | 全做成毛绒布偶，全废 |
| v2 | 光滑釉面反光 | 材质对但过头，用户「都有种釉面光泽，原图没有」；款4 帽上多绿叶 |
| **v3 ✅** | 「**哑光树脂/黏土质感：细腻颗粒、哑光不反光、无釉面高光和镜面反射、立体堆叠奶油霜般雕刻肌理；绝不是毛绒布偶/布料，也不是亮面陶瓷/釉面**」；款4「纯粉色帽、帽上绝对没有绿叶图案」 | 三款造型全部正确 |

**规则**：材质描述必须同时给出「是什么」和「不是什么」，且以**实际白底原图**为准，不凭锚点卡文字想象。

生成图天生偏鲜亮糖果色，需降饱和到莫兰迪奶油调：PIL 迭代 `0.72 → 0.5 → 0.45 → 回调 0.62 饱和 / 0.99 亮度 / 0.98 对比`，逐款对比原图确认。

## 7. 叙事／角色镜专用（借鉴 Higgsfield 方法论）

> 以上 §1–§6 面向**商品转盘**；做**人物、对话、多角色同框**的叙事镜时，额外补这三把锁。
> 共用底层仍是「一镜一件事」；本节只加「几何一致的量化语言」和「表演的写法」。

### 7.1 空间地图（Space Map）——治穿帮、换位、跳机位

- 每个场景**写一次平面图**（几行即可），然后**逐镜逐字粘贴**进提示词，不许凭记忆。
- 位置绑**可见地标**，不绑距离：
  - ✅「A 在落地灯旁、画面左侧；B 在沙发前、画面右侧；摄影机在房间南端朝向北」
  - ❌「A 在 B 左边两米」（模型没有米的概念，会乱放）
- 每镜明确**机位在哪一侧**（同一场戏的机位一旦定了就别过轴，否则人物左右互换）。
- 显式写人数上限：「画面里**正好三个人，其余全空**」（不写，模型会补龙套）。
- 三个高频病一次治：**瞬移**（位置写全）、**人物互换**（绑地标+定轴）、**机位跳**（机位方向每镜写死）。

### 7.2 镜头用「度数」不用「毫米」

- 镜头一律写**视场角度**：`180 / 135 / 107 / 84 / 63 / 47 / 29 / 18 / 12 / 8°`（10 个锚点）。
- **可靠工作带 29–84°**；更极端值模型容易糊或变形，非必要不用。
- 每镜**锁死一个度数**。不写，模型会默认滑向中间景别，导致同场戏景别忽远忽近、接不上。
- 例：「85mm 中景」→ 改写「**47° 视场、中景、机位在人物眼睛高度**」。

### 7.3 表演写「肌肉」不写「形容词」

- 情绪词（愤怒/悲伤/惊讶）模型只会给你一个**夸张脸**。改写**可观察的身体事件**：
  - ✅「下颌收紧、颊骨绷紧、呼吸变浅、手指在裤缝上停住」
  - ❌「他非常愤怒」
- 加**一句内心独白**（台词里不出现「怀念/嫉妒/心疼」这些词，但模型会据此反推微表情）。
- **行为替代情绪**：写「想要什么 → 遇到什么阻碍 → 策略怎么变」，每次策略变化都是一个**可见动作**。
- **声音是锁定条件，不是资产**：音色/语速/口音每次逐字粘贴复用，别指望"同一个人"的声线一致。
- **静态镜要有微事件**：每 1–2 秒一个微动作（眨眼分阶段、手指轻动），写「held tension」而不是「who moves」。
- **活镜头三标志**：反应先于台词结束就启动；情绪不瞬间清零（留个尾巴缝到剪辑点）；手始终有事做（最强的强调=手停住的那一刻）。

### 7.4 与其他规则的关系

- 与 §1「一镜一件事」不冲突：空间地图是"这一件事发生在哪、机位朝哪"，动作链仍是单件事。
- 与 §3「运镜约束」叠加：先定机位侧（7.1），再定这条轴怎么推（§3）。
- 与 §4「人物镜方向写死」叠加：方向写死 + 空间地图 = 人物镜一次过的双保险。
