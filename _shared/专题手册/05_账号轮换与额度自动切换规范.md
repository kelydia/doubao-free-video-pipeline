## 1. 硬规则

1. **额度不足自动切换，不必逐次人工确认**。依据用户 2026-11-15 21:52 的明确授权：出片任务中检测到额度耗尽即自动切到备用账号并**重提当前未完成镜头**（该镜头未生成成功、额度未扣，不属于「重跑」）。
2. **禁止 `quota → break` 就结束批次**。任何视频批次脚本命中额度耗尽，必须先尝试切号重试；切完账号池仍耗尽才允许停，并写台账。
3. **禁止硬编码 `taskSpace(数字)`**。一律 `taskSpace("<任务名>-production-<日期>")` 动态重连；账号切换前后、长时间后台作业前后都可能有 TaskSpace 过期（实测两次报 `Error: task space not found: 2/3`）。
4. **账号池以页面动态读取为准**，不硬编码账号名做切换决策。
5. **每次提交与每次切号都要记账**（§7）。
6. **仍需人工确认的边界**（§8）：新增/登录新账号、重跑已生成成功的镜头、改提示词重出、换账号重出已成功的内容、静态补位镜替代真视频。
7. **「额度不足自动切换」不豁免「视频生成前关键帧人工确认」**（工作区 `AGENTS.md` 2026-11-16 强制规范）：自动切号重提的镜头若关键帧未在本批次确认过，仍须先发图给用户确认；已确认且关键帧未变更的镜头无需重发。

## 3. 开工预检（每个出片任务必做）

1. 用 `taskSpace("<任务名>-production-<日期>")` 重连并打印 `task.spaceId`。
2. 读左下角 `currentAccount(page)`，确认登录态。
3. 打开账号面板，`readPanelAccounts()` 列出**所有**可用账号；少于 2 个 → 先向用户说明「账号池不足」，不要开跑长批次。
4. 生成前查 `quotaExhausted(page)`；若当前账号已耗尽，**先切到有额度的账号再开跑**，不要把额度检查留到提交后。
5. 估算本批次镜头数，按「单账号每日约 6 条免费视频」分配；超过 6 条时**预先计划切号点**，不要等打满。

## 4. 触发条件与自动动作（脚本必须实现）

```
for each shot:
    if 已生成成功 → skip
    while 未完成:
        r = runShot(shot)                  # freshChat → 视频模式 → 规格 → attach → 提交 → 等待
        记账(r)
        if r.done            → 完成，下一镜
        if r.captcha         → 停，交用户人工（handOff）
        if r.quota:
            if 切号次数 >= 账号池规模 → 停 + 台账标 all_exhausted（见 §6）
            sw = switchToFreshAccount(page)
            记账(sw)
            if !sw.ok        → 停 + 报告
            else             → continue   # ★ 同一镜头在新账号上重提，不跳过、不重跑旧片
        else (fail/no video) → 停该镜，按手册 04 §7 人工复查后再决定
```

- 触发正则：`/今日视频生成免费额度已用完|额度已用完/`。命中后**立即**处理，不要反复轮询重试（重试不扣额度但白耗时间）。
- 切号后必须重新走完整 `freshChat → clickVideoTab → setAspect → setDuration → attach → typeInto → clickSend → 确认补发`，因为切号会跳回 `/chat/` 并清空会话上下文。
- 长提示词会先回「确认后我再开始生成视频」→ 补发「确认，请直接开始生成视频」。

## 6. 失败回退（账号池全部耗尽）

按优先级，前 2 项**需人工确认**：

1. **等次日额度重置**：保留队列与 `video_status.json`，次日重连后只补未完成镜头（已成功的会被 skip）。
2. **新增账号**：点面板「添加账号」→ 需用户扫码/登录 → handOff， automation 不代替登录。
3. **静态补位镜（0 额度、当天可交付）**：手册 02 §4.1 / 复盘 2026-11-15 §65、68。`ffmpeg -loop 1` + `zoompan 1.04x~1.05x` 微推，把已验收关键帧做成 2.5–4s 视频；对「定格展示型」镜头（如 S9 的 1.6s 播放 + 2.4s 定格）与原设计几乎等价。
4. 无论选哪条，都要在台账与任务总结里写明「哪几镜是真视频 / 哪几镜是补位镜」。

## 8. 边界：仍然必须先人工确认

全局 `~/.dsh/AGENTS.md`「重跑必须人工确认」继续有效。自动切换**只豁免本节第 1 条列出的场景**：

- ❌ 自动切号 ≠ 自动重跑**已生成成功**的镜头。
- ❌ 自动切号 ≠ 自动换提示词 / 换参考图 / 换机位重出。
- ❌ 自动切号 ≠ 自动「添加账号」或代替用户登录。
- ❌ 若切号后**同一镜头仍反复失败**，停止并报告，不要无限重试（上限 = 账号池规模）。
- ✅ 出片任务中「额度耗尽 → 切备用号 → 重提该镜未完成的生成」：已获用户 2026-11-15 21:52 明确授权，无需逐次确认。
