## 2. 雨声：用 ffmpeg 合成，不必找素材

本地无雨声素材时，Python numpy 手写粉噪 + one-pole 带通**增益过低、波形空白**（失败）。成功方案：

```bash
ffmpeg -f lavfi -i "anoisesrc=color=pink:duration=16:sample_rate=48000:amplitude=0.6" \
  -af "highpass=f=400,lowpass=f=7000,volume=2.2,tremolo=f=0.25:d=0.25,\
aecho=0.8:0.6:40|85:0.3|0.2,alimiter=limit=0.9" \
  -ac 2 05_audio/sfx/rain_synth.wav
```

产出 16.085s / 48kHz / 立体声 / mean −25.8dB, max −13.2dB。

**核验方法**：分段 `volumedetect`（27–31s mean −17.8dB、31–37s mean −19.3dB，与 A 轨段 −18.4dB 齐平即合格）。
**坑**：白噪声的 `showwavespic` 波形图看着是平的，属正常，**不代表音量小**；要用 `volumedetect` 的 RMS 判断。

## 3. 末帧定格 / 静态微推

见 [02_参考图_衔接与补救.md](02_参考图_衔接与补救.md) §4.1 / §4.5。音频侧唯一硬约束：

## 4. 成片规格与交付口径

| 项 | 本工作区实际做法 |
| --- | --- |
| 分辨率 | **720×1280**（豆包原生），刻意保持一致，**不放大到 1080×1920** |
| 帧率 | 30fps（豆包原生 24fps，合成时统一 fps=30） |
| 时长 | A 轨 25.0s / B 轨三款 29.03s / 装袋版 37.07s |
| 花字 | 默认英文（GOAL! 等），impact 字体白字黑边；用户规范「默认英文成片」 |
| 音轨 | A 轨粗剪无音轨；正式交付含 AAC |
| 水印 | 保留豆包 AI 水印（去水印方案已证伪且成本过高，见 `经验_豆包去水印提示词.md`） |

Q 项目（11-11）成片是 1080×1920 / 34.000s / H.264 High CRF18 ~11.3Mbps + AAC 44.1kHz 192kbps，用 `compose_v3_nocap.sh` + `concat_nocap.sh`；**两个项目规格不一致，不要混用脚本**。
