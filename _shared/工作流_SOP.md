# 工作流 SOP：豆包网页版免费额度做商品短视频（v2）

> **来源**：`2026-11-11`《圣诞小熊挂饰》34s → `2026-11-13`《世界杯点球盲盒》A/B 轨模板 → `2026-11-15`《圣诞小熊装袋版》37s，三次项目的完整复盘。
> **v2 变更（2026-11-15）**：纳入 11-13 / 11-15 新经验；修正时间额度预算（5–7 分钟/镜，非 2–3 分钟）；新增「模板化 A/B 轨生产」与「补救工具箱」；把易踩坑的展开内容拆到 `_shared/专题手册/`，本文只保留主干 + 硬规则 + 索引。
> 每个新任务开工前过一遍本文件，能省掉当时踩过的 70% 的坑。

## 第一性原理（一切规则的由来，判断标尺）

> **「一致性就是全部工作，视频模型没有记忆。」** —— 借鉴自 Higgsfield《The Cully Hill Boys》开源方法论。

视频模型每生成一镜都从零开始、不记得上一镜。本文档**每一条**硬规则（锚点先行、空间地图、参考图检查、时长锁定、衔接两联图……）最终都是为了对抗「没有记忆」这一件事。遇到本文没覆盖的新问题，先问一句：**它会不会破坏镜与镜之间的一致性？** 会，就必须用「显式描述 + 参考图 + 两联判定」去补。

由此派生的三条不可动摇的纪律：
1. **资产先行**：任何一镜开跑前，它要用的资产（角色/场景/道具/商品）必须已锁定并命名；资产不在账上，就不许开工。
2. **每次说全**：提示词不依赖「上一镜它记得」，人物位置、机位方向、光线、道具数量每镜都写全。
3. **一次一变量**：每次重跑只改一处并记录；改多了无法归因，等于白跑。

## 第一部 · 主干流程

### 0. 开工检查清单（10 分钟）

- [ ] **先查 `templates/README.md` 有没有可复用模板**（T1 世界杯点球盲盒 = A 轨固定+B 轨换 SKU；T2 货车掉箱开箱 = 七镜六拍整条重做）。能复用 A 轨就是 0 额度。
- [ ] 商品图：白底主图 + 各款式图 + 场景层图 + **尺寸图**（区分清楚，场景层只借光影不借形状）
- [ ] 参考视频：1fps 抽帧目检 → 写逐秒结构表
- [ ] **账号额度预检（强制，见手册 05）**：`taskSpace("<任务名>-production-<日期>")` 动态重连 → `currentAccount()` 读登录态 → 打开账号面板列出 ≥2 个账号 → `quotaExhausted()` 确认当前账号未耗尽；本批次镜头数 >6 时预先排好切号点。视频批次脚本必须 import `_shared/scripts/acct_switch.mjs` 实现「额度耗尽 → 自动切号 → 重提当前镜头」，**禁止 `quota → break` 就结束批次**。
- [ ] 确认 ffmpeg / venv python 路径（见手册 04 §8）
- [ ] 建任务文件夹 `<YYYY-MM-DD>_<主题>/`，复制标准目录结构（见工作区 README.md）
- [ ] 先问清 5 个问题（见 §7）
- [ ] **视频生成前的关键帧人工确认（强制，2026-11-16）**：向豆包提交任何视频生成任务前，先把该批次的关键帧 / 首尾帧图发给用户看并取得明确「通过」；未确认不得提交。修复 / 重出场景额外发「上一镜末帧 + 本镜首帧」两联图。见工作区 `AGENTS.md`「视频生成前的关键帧人工确认」。
- [ ] **浏览器自动化 5 分钟硬停 + 激活层判定（强制，2026-11-16）**：非阻塞等待超 5 分钟无进展立即停、交回人工；点击前用 `activeLayer()` / `sendTarget()` 判定当前激活窗口与目标命中，禁止盲点固定坐标；发送失败或输入框仍留提示词立即中止。见工作区 `AGENTS.md`「浏览器自动化的『5 分钟硬停』与激活层判定」。
- [ ] **填 `00_input/product_anchor.md`，不要留空模板**（11-13 因此 B 轨早期 blocked）

### 1. 参考视频逆向（半天）

1. `ffprobe` 取分辨率/帧率/时长/码率。
2. `ffmpeg -vf fps=1` 和 `fps=2` 各抽一套帧，用 `sheet.py` 拼 contact sheet，带 `t=Ns` 标号。
3. 写 `01_plan/参考视频逆向.md`：逐秒结构表 → 镜头类型 → 叙事节拍（六拍模型：悬念 → 事件 → 揭示 → 聚焦 → 展示 → CTA）。
4. 提取「去 AI 味」手法清单：无口播 / 无人脸（只露手）/ 手持微晃 / 阴天低饱和 / 材质瑕疵 / 浅景深手机感 / 克制运镜。

**坑**：只写「看起来像」不算逆向；要能说出每一秒在干什么、用什么样的镜头语言。
**豆包不支持上传参考视频**：实拍素材只能抽关键帧图片当参考（手册 02 §5）。

### 2. 商品锚点卡（1 小时，最容易返工的一步）

写 `00_input/product_anchor.md`，必须包含：

1. **具名锚点**：颜色 hex、每个配件的具体形状/材质、可数元素。
2. **配色表**：主色 + 辅色 + 禁止色。
3. **⚠️ 包装**：真实包装长什么样，写在最前面，直接决定后面所有负向词。
4. **禁止项**：硬盒/礼盒/盲盒、尺寸牌、型号字样、手套样式（连指还是分指！），**点名具体物体**。
5. **一致性自检规则**：出图后逐条对照。

**教训**：包装写错一次，关键帧 + 视频全部重做，占整个工期的 40%。
**材质以实际白底原图为准，不凭锚点卡文字想象**（11-13 把哑光树脂写成毛绒，关键帧三轮返工；详见手册 01 §6）。

### 3. 分镜脚本（2 小时）

`01_plan/storyboard.json`（机器读）+ `分镜脚本.md`（人读）双版本，字段：

```
shot_id / seconds / caption / beat / framing
first_frame_prompt / last_frame_prompt / node_frames[] / consistency_lock / negative
```

规则：

- 每镜 4–6 秒（豆包视频生成滑块范围 **4–15s**，9:16；最小 4s）。
- **一镜只做一件事**：凡「撞+倒入网」「踢+随挥」「装+封+举」这类复合动作，写分镜时就拆成两镜（手册 01 §1）。**这是 11-13 / 11-15 返工最多的根因。**
- **动作型镜头起始状态写成「动作已完成一半」**，并显式反写错误（手册 01 §2）。
- 节点帧只在有复杂动作时加，1–3 张，说明「动作的关键中间状态」。
- `consistency_lock` 只约束**商品出镜时**；箱数不绑定商品数（11-13 硬约束，6 列×2 层=12 只即可）。
- 因果链显式写：上一镜的结束状态 = 下一镜的起始状态。
- 运镜：只沿一条轴推镜 + 降机位，不侧移不环绕；主体贴镜头构图显式写「4 秒内主体高度增加不到 10%」（手册 01 §3）。

### 4. 关键帧生成 + 人工确认（半天，最花额度）

#### 4.1 生产方式：锚点先行（C 模式，默认）

不要一次性把全片关键帧出完再统一进视频。按「环」推进，每环只锁 1 张尾帧：

```
环 n（以 S1 → S2 为例）
1. 先出 S(n)_first、S(n+1)_first      ← 两张一起锁死
2. 再出 S(n)_last                     ← 提示词写"结束画面必须收束到 S(n+1)_first 的构图/机位/落点"
3. 送审（两联图 contact sheet）：只看 S(n)_last 和 S(n+1)_first 能不能接上
4. 通过 → 跑 S(n) 视频
5. 视频出片后抽末帧，与 S(n)_last 对比
   - 偏离小 → 进下一环
   - 偏离大 → 用视频末帧去修正 S(n+1)_first（默认修图），而不是回头改 S(n)
6. 锁 S(n+1)_first 后，再出 S(n+1)_last 对齐 S(n+2)_first
```

**理由**：视频模型对参考图只是「参考」，严格串行会把「图不好」的锅反复甩给上一镜、变成无限重跑；尾帧是一张图，改图比改视频便宜约 20 倍，把约束放在最便宜、最可逆的位置。

#### 4.2 闸门强度

| 镜类型 | 闸门 | 说明 |
| --- | --- | --- |
| 商品出镜镜 / 复杂动作镜 | **硬闸门** | 必须等上一环视频出片并检测通过，才能进下一环 |
| 环境镜 | **软闸门** | 可并行出帧；偏差可用 0.3s 转场或调色掩盖，不值得串行 |

#### 4.3 「视频末帧偏离大」时的默认策略

**任何重跑都必须先经人工确认**——包括重跑视频、重跑关键帧、重跑下一镜首帧、换提示词、换账号。自动化只负责出证据，不自动执行。

**判定口径**：

1. **以 `join` 两联图为准**（左＝上一镜视频末帧，右＝下一镜首帧），判断叙事与空间上能不能接上：方向、物件是否已脱离、镜头高低角、主光方向。
2. **`drift` 数值只作参考，不作硬指标**。动作推进型末帧与静态关键帧的像素差天然很大，但衔接可成立（S1 实测 drift=74.46 仍放行；S7 `mean_abs_diff=18.4` 网绳余振属预期内）。
3. 可把「**硬切处帧间差异 < 15**」当辅助门槛（11-13 实测：用户自拼两段硬切点 45.4，正常帧 7–10）。
4. `drift` 适合抓真问题：主体完全跑偏、物件消失/多出、方向反转。

**流程**：`anchor_gate.py` 出证据 → 我给判断（能接/不能接，修图还是重跑视频、各花多少额度与时间）→ 用户确认后才执行。**默认建议 ≠ 默认执行**。

**默认建议修图**；建议重跑视频仅限：修图会破坏方向性元素（文字、logo、单侧光、明确左右关系）、或偏差来自视频里的动作错误（道具数量、手势错）。

#### 4.4 出图与送审细则

1. **先确认「图像生成」模式**：`freshChat` 不切模式，页面会残留上次的「视频生成」→ 豆包把关键帧当视频做。用 `gen2_img.mjs`（手册 04 §1）。
2. refs 链式传（同一环内 `S(n)_first → S(n)_last → S(n+1)_first`）；**只挂 1 张参考图最稳**，多图会互相干扰。
3. 每张图出完：`finalize_frames.py`（裁底部 6.2% 水印条 + 缩放到 1080×1920）；顶部纯色黑边要先裁（119px / 134px）。
4. contact sheet 分批送审，**一次只审 4–8 张**，用户确认后才进视频。
5. 不合格的帧，先分析是「动作不对」还是「物体不对」，再改提示词重跑，不要盲目重试。
6. **用参考图前逐项检查「图里有什么」**——球、文字、多余道具会被忠实复制（手册 02 §1，11-13 最贵的一课）。

#### 4.5 审图看图的成本纪律

> **唯一权威见工作区 [`AGENTS.md`](../AGENTS.md)「看图成本纪律」**（token 表 + 三条硬规则 + 标准命令）。此处不再复制。
> 要点：永不直读 720×1280 / 1080×1920 原图，先过 `_shared/scripts/review_sheet.py`；一次一张；动作/机位/箱数 `strip --h 330`，包装/材质 `one --h 900`。
> **`pair` 接受 (上一镜视频, 下一镜首帧静态图)** —— 第一参数取视频末帧、第二参数当图片打开（实测可用），输出落 `_shared/scripts/.cache/work/`。

### 5. 单镜视频生成（最耗时间）

- **必选视频时长（强制，2026-11-16 血泪）**：豆包视频页默认是 **10 秒**，若「时长/比例」菜单未点到（脚本报 `menu not opened`），会静默按 10s 生成，节奏全毁。**提交前必须确认视频页出现的「比例/时长」规格控件并逐镜设到目标秒数**（如 2s/3s/4s），或确认提示词里的秒数与实际一致后再提交；出片后用 `ffprobe` 复核 `duration` ≈ 目标值，偏差 >0.5s 即判该镜不合格。注意豆包视频页可能没有「9:16 · Ns」胶囊而是把比例写进提示词、提交后弹「视频生成参数确认」卡（显示默认 10 秒/9:16）——**此时必须在确认卡上把时长改对再确认**，不能直接确认 10s。
- 每次提交 1–2 张参考图 + 结构化提示词；**中文引号用「」，写完 `json.load` 校验**。
- 每镜预期 1–3 次重跑；`_prev/` 存旧版，最新合格版复制成无后缀名。
- 逐镜抽帧目检：机位方向、道具数量、落点位置。
- **每镜出片后必做**：抽末帧 → 与下一镜首帧做两联对比 → 决定「放行」还是「修下一镜首帧」（§4.3）。
- **出片耗时 5–7 分钟/条**（11-13 实测，非早期文档写的 2–3 分钟）；图片 25–35 秒/次。>10 分钟无响应才判失败重提。
- **报 no video 不要直接重跑**：`vid.mjs` 的 done 正则会漏「你的视频生成好了」变体 → 人工开页面复查 + `grab.mjs` 二次抓（手册 04 §5）。
- **失败不扣额度**（S6 v2 页面明确「视频生成失败，生成额度未扣除。」）。

### 6. 合成与质检（半天）

- **合成前统一 `scale=720:1280,fps=30`**（豆包原生 24fps），用 `filter_complex concat=n=<段数>:v=1:a=0`。
- 本工作区成片统一 **720×1280 / 30fps**，刻意不放大到 1080×1920（11-11 项目是 1080×1920，两个项目规格不同，**不要混用合成脚本**）。
- 混音用「事件点表驱动」，输出 `loudnorm=I=-16:TP=-1.5:LRA=9`（手册 03 §1）。
- 末帧定格时 **silence = FREEZE_T + HOLD**，否则音轨短一截。
- 质检三张图：`fps=1/4.8 tile=7x1`（整体调性）、`fps=1 tile=6x6`（逐秒/衔接/闪帧）、相邻镜交界帧（衔接）。
- **默认输出**：英文花字（用户规范）；无口播、不拍正脸、只要氛围。

#### 6.1 Watcher 通看（合成后必做，借鉴 Higgsfield「专职审片」）

`anchor_gate.py` 只判「相邻镜衔接」；它查不出**单镜内部「技术上存在、但看着不成立」**的问题。
合成后，指定一个人（或自己切换成"陌生观众"视角）**从头到尾通看一遍成片**，逐条过下面清单：

- [ ] **空首帧**：有没有哪一镜开头 0.3–1s 是空的/无主体的（模型最容易送空帧）。
- [ ] **表情跳变**：同一个人前后两镜表情/年龄感/发型是否突然变了。
- [ ] **动作不同步**：嘴和声音、手和物体、脚和地面是否对得上。
- [ ] **道具数量/位置漂移**：场景里的箱子、球、道具数量有没有莫名增减或瞬移。
- [ ] **穿帮**：多余的人、不该出现的文字/logo、参考图残留元素。
- [ ] **节奏**：生成内容天然拖沓，是否该剪掉的 0.5s 头尾没剪。

> 依据：Higgsfield 实践——「一个废镜头毁口碑，在合成阶段抓到一个只需改一行提示词」。抓到的问题按 §12 补救工具箱处理；属单镜硬伤的，**改镜头不硬修**（见第 13 条 / U5）。

### 7. 开工前必须问清的 5 个问题

### 10. 分镜生成模式对照

| 模式 | 做法 | 一致性 | 串行深度 | 预期工期 |
| --- | --- | --- | --- | --- |
| A 一次性 | 全部关键帧出完 → 全部视频 | 中，靠人工兜底 | 0 | 3 天 |
| B 严格串行 | 出本镜首帧 → 视频 → 检测通过 → 才出下一镜首帧 | 最高 | 7 | 5–7 天，易陷入无限微调 |
| **C 锚点先行（默认）** | 先锁 `S(n)_first + S(n+1)_first` → 出 `S(n)_last` 对齐 → 跑视频 → 抽末帧检测 → 放行 | 高 | 3（仅硬闸门镜） | **2–2.5 天** |
| **D 模板化（多 SKU 首选）** | A 轨固定渲一次 + B 轨每 SKU 只重做尾镜 | 高（A 轨天然一致） | 0 | A 轨 1 次 + 每 SKU 40 分钟 |

**否决 B 的理由**：豆包视频模型对参考图只是「参考」，严格串行的等待条件几乎永远无法稳定满足，会把重跑风险无限累积。
**闸门判定以 `join` 两联图为准，`drift` 只作参考**（§4.3）。

工具：`_shared/scripts/anchor_gate.py`
- `join <上一镜视频> <下一镜首帧> --out x.png` → 主判定依据
- `drift <上一镜视频> <上一镜尾帧>` → 只用于抓「主体跑偏/物件消失」

## 第二部 · 11-13 / 11-15 新增方法

### 11. 模板化生产：A 轨固定 + B 轨换 SKU（最重要的产能升级）

当一个创意要覆盖多个商品时，不要「每 SKU 整条重做」：

```
A 轨（固定叙事，渲一次全店复用）：S1…S6a → TRANSIT（25s）
B 轨（每 SKU 一条）：S9 开箱见商品（4s）
```

- **A 轨复用成本 = 0**：11-13 的 A 轨 v3 被三款小熊、快递袋版、装袋版反复复用。
- **B 轨每 SKU**：1 张关键帧 + 1 条视频 ≈ 40 分钟。
- 箱位变体：`hflip` 镜像（0 额度，须画面无单侧文字/logo）、重渲（3 次视频）、目标箱高亮（PIL 叠呼吸光圈，0 额度，换 SKU 只改 `target_col` 一个数字）。
- 每完成一个新创意视频 → **自动沉淀为模板**（`templates/README.md` 的入库规则），无需用户再要求。
- 已入库：**T1 世界杯点球盲盒**（A 轨 25s + B 轨 S9 4s）、**T2 货车掉箱开箱**（七镜六拍整条重做）。

### 12. 补救工具箱（按性价比排序）

两镜接不上、或画面里多了不该有的东西时，按此顺序选：

| 手段 | 成本 | 适用 | 详见 |
| --- | --- | --- | --- |
| **静态补位镜** | 0 额度 / 130KB | 上镜末帧可用，下镜重渲总不对 | 手册 02 §4.1 |
| **桥接过渡镜 TRANSIT** | 1 额度 | 两段独立生成视频机位/景别对不上 | 手册 02 §4.2 |
| **0.1s 白闪硬切** | 0 | 机位小幅差异，不值得重渲 | 手册 02 §4.3 |
| **删镜** | 0 | 镜头有硬伤（如 S7 全程带抹不掉的球） | 手册 02 §4.4 |
| **末帧定格 / 静态微推** | 0 额度 | 补成品展示、避免取出穿帮 | 手册 02 §4.5 |
| 后期 delogo / inpaint | 别试 | 球压在三材质交界，三种手段全糊 | 手册 02 §2 |

**核心推论**：豆包视频模型对参考图是「忠实复制 + 自由演绎」，不是精确复刻；**所有可控性都要靠输入侧约束买，不能靠后期修**。

### 13. 三条必须内化的硬规则

1. **参考图会「带入」元素**：图里有球，模型必画球；用图前逐项检查，备「无球版」参考图，提示词写死「全程绝对不能出现球」。
2. **复合动作一镜必翻车**：拆段，每段只做一件事（S6→S6a+S6b，S10→S10a+S10b）。
3. **动作型镜头写「已完成一半」的起始状态**：S5 v1 写「完成抽射随挥」被演成倒放，v2 写「球已在空中、脚停半空」一次过。

> **补充（第 4 条，借鉴 Higgsfield）：镜头救不回来，就改「镜头」不要改「措辞」。**
> 同一条提示词改到第 3 版仍不成立，通常不是话没说圆，而是**这个镜头本身太难**。
> 正确动作是把镜头**拆小/换机位/减少同时发生的动作/换更简单的调度**——Higgsfield 的复盘是「每一个被救回来的废镜，都是靠改镜头救回来的，从没靠改句子救回来」。
> 这条与第 2 条一体两面：第 2 条治"一镜塞太多"，第 4 条治"改不出来时别再抠字"。

### 13.1 剪辑与生成并行（借 Higgsfield「剪辑并行」）

- 生成是**分钟级**的慢活（5–7 分钟/条），**剪辑不该等全部生成完才开始**。
- 出片几镜后即可开始粗剪，用已有镜头摆节奏、暴露缺口；**剪辑过程本身会告诉你哪一镜要重出、哪一镜要重排**。
- 生成内容**天然拖沓**：剪的力度要比直觉更狠，默认预留**剪掉每镜头尾各 0.5s** 的冗余（生成时段前后常有轻微呆滞）。
- 画面锁定后再做**独立调色/打磨**一遍；真正坏掉的镜头**重出**（在已存的提示词里改一行即可，因为提示词库完整且版本化），不要在剪辑里硬修。
