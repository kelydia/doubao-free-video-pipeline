# 资产系统规范（Assets System）

> 借鉴自 Higgsfield《The Cully Hill Boys》开源资产体系。
> 定位：本规范是**叙事/角色/场景类镜头**（不是纯商品转盘）的一致性底座。
> 现有 `product_anchor.md` = 本体系中的「商品层」，保留不动；本规范补上它缺的角色层 / 场景层 / 道具层 / 状态层。
> 上位总纲：`../工作流_SOP.md` §第一性原理 ——「一致性就是全部工作，视频模型没有记忆」。

---

## 0. 一句话定义

**资产 = 文字描述（逐字粘进每条提示词） + 参考图 + 版本号。**
一个资产在账上，这一镜才允许开拍；资产不在账上，先建资产再谈生成。

---

## 1. 四层资产

| 层 | 前缀 | 是什么 | 举例 |
| --- | --- | --- | --- |
| 角色层 | `@char_` | 主角/反派/配角/动物的角色卡（含状态态） | `@char_CB_Kel_v9` |
| 场景层 | `@loc_` | 场景基图（3/4 角 medium/wide 基准） | `@loc_CB_warehouse_s6_v2` |
| 道具层 | `@prop_` | 有戏的关键道具 | `@prop_CB_gunTobin_s26_v2` |
| 商品层 | （沿用） | 现有 `product_anchor.md` 的 SKU 白底图 + 描述 | 见 T1/T3 模板 |

> **构图基线**：场景基图一律 3/4 角、中/远景，**不正面平拍**（正面=平墙纸，模型会把画面边缘之外全凭空编造）。
> 每个场景给一个**锚点物**（柱子/灯/沙发），人物走位绑到锚点上（"站在灯旁/画面左"），而不是绑距离。

---

## 2. 命名规则（可追溯）

```
@char_<项目>_<角色名>_v<版本>#<状态>
@loc_<项目>_<场景名>_s<场次>_v<版本>
@prop_<项目>_<道具名>_s<场次>_v<版本>
```

- **同名贯穿三处**：资产台账、提示词、画布图层，必须字字一致，方便反查。
- **版本只增不改**：新版本用新名字（`_v2`），**绝不覆盖**旧版本。
- **状态是独立资产**：同一个人的「干净外套态」和「打完架带血态」是**两个资产**，不是一个资产的两个描述。
  新状态只写「相对原始卡改了什么」，从而保留皮肤/材质纹理一致性。

示例（Cully Hill Boys 风格）：
- `@char_CB_Cal_v9#clean`（干净态）
- `@char_CB_Cal_v9#bloody`（战后态，只改"外套破口+颧骨血迹"，其余继承 clean 卡）
- `@loc_CB_warehouse_s6_v2`
- `@prop_CB_gunTobin_s26_v2`

## 3. 角色卡三禁忌（每条都来自一次翻车）

角色卡标准 = **三格**：正面全身 + 背面全身 + 一个 3/4 特写。规约：

1. **去头双身**：两张全身格里**去掉头部**。否则脸会被复制成"软糊"污染远景；脸只保留在特写格里。
2. **双表情特写**：做**两张**特写——一张笑、一张不笑。否则第一次笑的镜头会凭空长出牙齿/下颌。
3. **禁词「studio」**：绝不写 studio/影棚。模型会画出摄影棚、灯架，并把主光烘死进后面所有镜头。改写成 `no studio, no equipment, no walls`。

附加硬规：
- **无轮廓光**（rim light 会串场景）；
- **空手**：卡里出现的道具永远拿不掉，所以角色卡手里什么都不拿；
- **扛造测试**：资产要能连续生成 10 次仍可辨认；角色 + 场景必须**合测**（独自成立不等于同框成立）。

## 4. 台账模板

新建任务时，在 `00_input/` 放一份 `asset_index.md`（模板见 `templates/_asset_index_template.md`），逐行登记：
资产名 / 层 / 版本 / 对应参考图路径 / 一句话描述 / 状态（⬜待建 🟨生成中 ✅已锁）/ 最后校验日期。

**铁律：镜头提示词里只能引用 `✅已锁` 的资产名。**

---

## 5. 与现有流水线的接口

- **锚点先行 C 模式不变**：§4 先锁 `S(n)_first + S(n+1)_first` 仍是主流程；资产系统是把"锁什么"讲清楚。
- **参考图挂图纪律不变**：单镜挂 1–2 张（豆包多图会互相干扰），即"本镜用到的 1–2 个已锁资产"。
- **商品层平移**：纯带货转盘类任务可只用商品层 + 场景层的锚点物，不必强行上全套角色卡。
- **看图纪律不变**：所有参考图先过 `review_sheet.py`，绝不直读原图。
