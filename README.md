# 豆包免费视频生成 · 工作区说明

本工作区存放"用商品图 + 参考视频，在豆包网页版免费额度下批量生产带货短视频"的全部任务。

## 目录约定

```
豆包免费视频生成/
├── _shared/                     跨任务复用资产（不放单个任务的东西）
│   ├── 工作流_SOP.md            主干流程 + 硬规则（v2，2026-11-15）
│   ├── 专题手册/                01 提示词与动作 / 02 参考图衔接补救 / 03 音频合成 / 04 工程环境编码账号 / 05 账号轮换与额度自动切换 / 07
│   ├── templates/               T1 世界杯点球盲盒 / T2 货车掉箱开箱 / T3 美式橄榄球射门盲盒（可复用模板）
│   ├── 复盘_2026-11-15.md       三次项目复盘、返工根因、20 条经验索引（历史·只读）
│   ├── 豆包网页版操作手册.md     浏览器层唯一权威：选择器、比例时长、上传、发送、下载（v2）
│   ├── 经验_豆包去水印提示词.md
│   ├── 外部素材资源库.md         外部音效/特效备选来源、授权、归档
│   ├── 复用资产登记.md           脚本与资产台账（AUTO 由 project_retro.py 生成）
│   ├── 账号额度台账.md           账号切号记账（acct_switch.mjs 自动追加）
│   ├── scripts/                 通用脚本、review_sheet.py、ego-browser 技能全文
│   └── models/                  LaMa 等模型（纯 ASCII 路径，torch.jit 要求）
├── _archive/                    历史档案（结构整理方案、文档治理备份等，已移出活文档区）
└── <YYYY-MM-DD>_<商品或主题>/    一个任务一个文件夹（见下方标准结构）
```

### 任务文件夹标准结构

```
<YYYY-MM-DD>_<主题>/
├── README.md            本任务的交付说明（含已知限制）
├── 00_input/            商品一致性锚点卡、素材清单 manifest
├── 01_plan/             参考视频抽帧与逆向、storyboard.json、分镜脚本.md
├── 02_keyframes/        关键帧原图（*.png）+ final/（裁水印缩放后的 1080×1920）
├── 03_clips/            豆包生成的单镜原始片 + 备用版本（_prev/）
├── 04_review/           各阶段审片图（contact sheet）与验收记录 md
├── 05_audio/            音效/BGM 素材、混音中间件
├── 06_deliver/          最终交付物（成片 + 总览图 + README）
├── .egotasks/           ego-browser 自动化脚本与运行日志
└── scripts/             本任务专用脚本（通用的复制自 _shared）
```

> 过程产物（临时审片图、抓取缓存、试听脚本、concat 中间件）一律放 `_` 前缀子目录，
> 任务定稿后归档到 `_archive/` 或清理，不要散落在正式目录里。
> 旧任务 `2026-11-11_圣诞小熊挂饰` 原用 `05_edit/`，2026-11-15 结构整理时已统一为 `05_audio/`；过程产物归入各任务 `_archive/`（[方案](../_archive/历史方案/结构整理方案_2026-11-15.md)，已执行）。

## 命名规范

- 单镜素材统一用 `S1`…`S9`；重跑用版本号后缀 `S1_v2`、`S1_v3`…，**最新合格版复制成无后缀名**再进合成。
- 成片文件名：`完整视频_<商品名>_<款式>.mp4`（本工作区实际用法）；跨任务复用时也可用 `成片_<商品名>_<时长>s[_nocap|_en|_zh].mp4`。
- 审片图：`<主题>_五帧.jpg`、`<主题>_衔接.jpg`；一律用 `_shared/scripts/review_sheet.py` 生成，禁直读原图。
